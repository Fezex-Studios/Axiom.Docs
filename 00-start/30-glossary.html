Glossary#

Term Meaning in Axiom
Access level An account's staff rank in axiom_auth.accounts: 1 player … 3 Community Manager, 4 Game Master, 5 Developer. Re-checked on every GM command. Staff
AGDB The magic/format name of gamedata.bin (currently version 4). gamedata.bin
AOI / interest Area of interest: which entities each player knows about (spawn radius 75 m, despawn 85 m). Interest & replication
Auth The account service (HTTP 3000): login, tokens, world list, gamedata.bin downloads.
Baseline The first full state of an entity a client receives after acknowledging its spawn; snapshots are applied on top.
Bulk / World / Chat / Control channel The four LiteNetLib channels; ordering is per channel. Networking
C2W / W2C / W2P / P2W Packet direction prefixes: client→world, world→client, world→persistence, persistence→world.
Catalogue (server) a system's content loaded from worldserver.db at boot and kept in memory; (client) definitions sent in a W2C…Catalog packet.
CharacterMotor The shared movement simulation in Axiom.Movement, run identically by client and server. Movement
CombatRules Key/value table of tuning numbers (stat formulas, combat, PvP, siege...) read into GameRules.
Component A per-system part of a PlayerSession (Inventory, Quests, Equipment...). Saved ones implement IPersistentComponent.
Content Studio The Unity editor for every content table. Content Studio
Doodad Any interactive world object (ore, herb, chest, crop, station, door, portal) - a data-driven state machine. Doodads
Effect One row of the polymorphic Effects table: a verb (damage, heal, apply status, give item…) owned by an item, skill, status, doodad function or skill step.
Epoch The movement session number; a teleport or world entry starts a new one, so stale inputs are ignored.
Floating origin The client shifts the whole world back toward (0,0,0) to keep float precision; network positions stay in world space. World streaming
Full save W2PCharacterSaveFullRequest: a whole-character snapshot written in one MySQL transaction, ordered by SaveSeq. Persistence flow
Gamedata.bin The encrypted client content package (items and gear visuals).
HLOD / proxy A baked low-detail stand-in for a tile, shown beyond the streamed 3×3.
InternalSecret The shared secret services use to trust each other (x-internal-secret header). Same in all four configs.
Interest manager The server's AOI grid (InterestManager, 50 m cells).
Labor classic MMO-style account-wide action points spent on gathering and crafting.
Launch token One-use, 120 s credential from Auth that the client redeems at the World server. Login flow
Model key / ModelType A string naming a client prefab in WorldObjectPrefabs (NPC_ORC, IronVein, Character_Human_Female).
Movement collision The exported triangles (manifest.acm + .actri) both sides collide with; its SHA-256 is the collision hash.
NetworkId A runtime id for an entity in the world (players, NPCs above NpcIdBase, doodads); not stable across restarts. CharacterId is the stable one.
Outbox A list of operations owed to another service, saved with the character (WorldOutbox), so economy actions are never lost or duplicated.
Patch (SQL patch) A numbered .sql file in SQL/patches that adds content; applied once, tracked in schema_versions.
Persistence The player-data service (HTTP 7778) over MySQL axiom_persistence.
Phase A doodad's state (Full, Depleted, Open...), with its own visual and actions.
Protocol version ProtocolVersion.Current (45); the connection key Axiom/45 must match or the client is refused.
Shard / world One World server instance and its seamless world; listed in Auth's world directory.
Skill plot / step A multi-stage skill (SkillSteps): combos, channels, projectiles, chains, conditions.
Snapshot The batched binary W2CWorldSnapshot with positions of everything a player sees, once per tick.
Spawn ack C2WSpawnAck: the client confirms it created an entity, so the server starts sending its snapshots.
State class A static client class caching server state and raising events (LocalCharacterState, QuestState...).
Tick One step of the World server's simulation (20 Hz); everything that touches game state runs on the tick thread. World server
Tile A 512 m square of the world grid; on the client a tile_X_Z scene.
ToolkitWindow Base class of client UI windows (UI Toolkit). UI
Trade pack classic MMO-style goods carried on the back to an outlet for profit. Trade packs
worldserver.db The World server's SQLite content database. worldserver.db
Zone / zone key A painted design region with a permanent key (sunreach_1), PvP mode and banner. Zones
