18. Adding the Ranger Boots and a Sword (current setup)#

Step by step, using everything that's in Axiom now: the Character Pipeline, split bodies, Hide body parts, variants, Weapon Sheaths and body sockets. Guide 16 tells the story of how we got here; this is the clean recipe.

Before you start, check once:

Check Where Should show
Tools point at the server's database Dev Tools > Overview > World database a folder ending bin\Debug\net10.0\Data
Both bodies assigned Characters & Races > Bodies Default_Male_Char and Default_Female_Char in the Male / Female slots
Both bodies split Characters & Races > Sockets > Body parts card ✓ Split, for each body
Both bodies have sockets Sockets page all rows ✓
Outfit pack imported Assets/AxiomMMOKit/Axiom.Client/Art/Gear/Outfits/ Male_Ranger_Feet_Boots, Female_Ranger_Feet prefabs

Part 1: The Ranger Boots#

The pattern for all body armour: one item; the male model is the base ("Everyone"); the female model is its "Female" variant; the item hides the body part it covers.

1.1 Create the item#

Tools > Axiom > Create > Item… → Copy an existing one (a pair of boots):

Field Value
Name Ranger Boots
Icon name a PNG in Resources/Icons/ (guide 10)
Gear stats → EquipSlot 5 (Feet)
Gear stats → ArmorKind 2 (Leather)
Gear stats → ArmorRating 6
Sold by your vendor's shop, with a Buy Price

Check → Create. Note the item id.

1.2 The male look (Everyone)#

Tools > Axiom > Characters & Gear > Gear Workshop:

  1. Body: Human, Male.
  2. Item id → Load. Equip slot: Feet.
  3. Gear prefab: Male_Ranger_Feet_Boots.
  4. Attach: Skinned.
  5. Hide body parts: Feet. The bare feet are hidden inside the boots. (If the boots come up over the calves, add Legs only if the pants always cover the legs too; otherwise leave it at Feet.)
  6. Preview in Scene → "Armour bound to the body's bones." The feet don't poke through.
  7. Save for: Everyone → Save to world database.

1.3 The female look (Variant: Female)#

  1. Body: switch to Female. Load again.
  2. Gear prefab: Female_Ranger_Feet. Preview in Scene → bound.
  3. Save for: Variant: Female → Save as 'Female' variant.

⚠ Don't press Save to world database with Everyone selected here: that would make the female model the base for everyone. Hide body parts and the slot come from the base row, so the female boots hide Feet too.

1.4 Ship it and test#

  1. Overview > Export game data now. Restart the World server.
  2. Characters & Races > Wardrobe: Ranger Boots shows base on the male body, ✓ Female on the female.
  3. In game: buy and equip on a male and a female character, and walk around. No skin should show through.

Part 2: A sword#

Weapons are Socket gear: rigid, held at the body's MainHand socket, sheathed at the spot its weapon kind says (Content Studio > Weapon Sheaths: swords go on the left hip).

2.1 The body sockets (once per body; skip if done)#

Characters & Races > Sockets, for each body:

  1. Reference weapon: any sword built to the rule below.
  2. MainHand → Line up → rotate and move the socket until the sword sits in the fist, pointing forward → Save sockets to the prefab.
  3. HipLeft → Line up → it hangs at the left hip, blade down and a little back → Save sockets to the prefab.

Best final check: in Play Mode, equip and draw, pause, rotate the live Socket_MainHand until it looks right, Transform > Copy > Component, stop, open the body prefab, Paste > Component Values on Socket_MainHand, save.

2.2 Build the sword prefab to the rule#

Root at the centre of the grip; blade along +Y (green); edge along +Z (blue). Scene toolbar on Pivot and Local.

  1. Hierarchy → Create Empty Sword_Ranger: 0,0,0 / 0,0,0 / 1,1,1.
  2. Drag the sword model onto it (a child).
  3. Rotate the child until the blade points up the green arrow (0,0,90, 0,0,-90, 90,0,0 or -90,0,0).
  4. Rotate the child around Y until the edge faces the blue arrow.
  5. Move the child until the root sits where the fist closes.
  6. Size changes go on the child. Drag Sword_Ranger into Assets/AxiomMMOKit/Axiom.Client/Art/Weapons/, delete it from the scene.

The root's own transform is overwritten in game, so never adjust the root.

2.3 Create the item#

Create > Item… → copy a sword:

Gear stats Value
EquipSlot 6 (Main Hand)
WeaponKind 1 (Sword: Warriors)
TwoHanded off (on = carried on the back)
AttackPower e.g. 25

Plus Sold by. Create, note the id.

2.4 Fit it#

Gear Workshop:

  1. Body: Human / Male. Item id → Load (reads the weapon kind).
  2. Equip slot Main Hand; Gear prefab Sword_Ranger.
  3. Attach: Socket. In use: (the slot's hand). Sheathed: (by weapon kind). The line under them reads drawn on MainHand, sheathed on HipLeft (from Sword in Weapon Sheaths).
  4. Position and Rotation 0; Scale 1.
  5. Preview in Scene; tick Preview sheathed. Switch the body to Female and Rebuild preview: each body uses its own sockets.
  6. Optional Sheathed size (0.85-0.95) if it clips the leg.
  7. Save for: Everyone → Save to world database. No Female variant: the sockets already fit each body.
  8. Export game data now, restart the World server. In game: equip, draw, sheathe, run.

When something's off#

Looks like Fix
Skin through the boots Hide body parts: Feet on the boots, and the body is split (Sockets > Body parts ✓)
Bare legs vanish with the boots Hide body parts includes Legs: set it to Feet only
Women wear the men's boots the Female variant wasn't saved (1.3), or the female body isn't assigned
Boots float or stretch the boots don't match this skeleton: Pipeline > Test binding
Every weapon wrong in the hand the body's Socket_MainHand (2.1)
Only this sword wrong its prefab breaks the rule (2.2)
Sword on the back, not the hip Sheathed isn't (by weapon kind), or TwoHanded is on
"You can't use that" swords are Warrior weapons

Checklist#

  • [ ] Item created: EquipSlot set, armour / weapon kind set, sold somewhere
  • [ ] Boots: male → Everyone, female → Variant: Female, Hide: Feet
  • [ ] Sword: prefab to the rule, Socket, automatic sockets, offsets 0
  • [ ] Export game data now, World server restarted
  • [ ] Wardrobe ✓; tested on a male and a female character
  • [ ] New patch files and prefabs committed
