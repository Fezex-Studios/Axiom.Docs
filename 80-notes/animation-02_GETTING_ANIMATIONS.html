Animation Handbook

02 Getting and importing animations#

Animations are made by animators in tools like Blender or Maya, or captured from real actors. Almost every indie MMO starts from ready-made libraries and only commissions custom work later.

Sources#

Source Cost Best for Rig
Quaternius Universal Animation Library (already in Art/Animations/Quaternius/UAL1_Standard.fbx) Free (CC0) Locomotion, sword attacks, casting, interact, pick up, sit, death Humanoid
Mixamo (mixamo.com, free Adobe account) Free Huge humanoid catalogue: wood chopping, mining with a pickaxe, picking up, spell casts, emotes, riding poses Humanoid
Unity Asset Store class packs (sword and shield, two-handed, magic, archery, spear) Usually $15-60 Polished, consistent class skill sets with idles, combos and casts Humanoid
Creature and animal packs (horses, griffins, wolves, dragons) Free to $60 Mounts, pets, monsters: model, rig and clips together Generic

Check each source's licence for commercial use. Quaternius is CC0; Mixamo allows use in games; Asset Store assets use the Asset Store EULA (fine for games; you can't resell the raw files).

Mixamo, step by step#

  1. Sign in at mixamo.com. Optional: upload your character (FBX) so previews show your body; any humanoid character works for downloading.
  2. Search for the animation ("chopping", "mining", "picking up", "standing 1H magic attack").
  3. Adjust the sliders (speed, arm space), and tick In Place if offered (Axiom moves characters from the server; animations must not move the character themselves).
  4. Download: Format FBX for Unity, Skin Without Skin, Frames per second 30.
  5. Drop the FBX into Art/Animations/Mixamo/<Category>/ (for example Mixamo/Gathering/).

Import settings (select the FBX, then the Inspector)#

Rig tab - Animation Type: Humanoid (people) or Generic (animals, creatures). - Avatar Definition: Create From This Model for the first FBX of a set. For more clips from the same source you can Copy From Other Avatar to share one avatar. - Press Apply, then Configure... to check every bone circle is green.

Animation tab (for each clip in the list) - Loop Time: on for anything that repeats (idle, walk, run, chopping, mining, channelling, flying); off for one-shots (attack, cast release, death). - Loop Pose: on for loops, so the end blends into the start. - Root Transform Rotation / Position (Y) / Position (XZ): Bake Into Pose on all three, based on Original. The server owns movement, so the clip must stay in place. - Name: rename clips clearly (see naming below). Press Apply.

Materials tab: only matters for FBX files with a model; extract and convert to HDRP as in CHARACTER_ANIMATION_README Part 3.

Naming conventions#

Consistent names make controllers readable and searchable:

Kind Clip name Parameter name
Gathering loop Gather_Chop_Loop, Gather_Mine_Loop, Gather_Pick_Loop Chopping, Mining, Gathering
Class skill Warrior_ShieldBash, Mage_Fireball_Release, Mage_Fireball_Cast_Loop ShieldBash, Fireball
Shared combat Combat_Attack_1H, Combat_Hit, Combat_Die Attack, Hit, Die
Mount gaits Horse_Walk, Horse_Gallop, Griffin_Fly, Griffin_Glide, Griffin_Land Speed, Flying, Grounded

Parameter names match the skill's AnimationParameter exactly (capitals count) and have no spaces.

Folder layout for animation assets#

Art/Animations/
  Controllers/           AxiomCharacter.controller, creature controllers, override controllers
  Masks/                 UpperBody.mask and other avatar masks
  Quaternius/            UAL1_Standard.fbx (and later packs)
  Mixamo/
    Gathering/  Combat/  Classes/Warrior/  Classes/Mage/  ...
  Classes/<Class>/       purchased or custom class sets
  Creatures/<Creature>/  Horse/, Griffin/, Wolf/  (model + clips + its controller)

Testing a clip before wiring it#

Drag your character prefab into an empty scene, select it, open Window > Animation > Animation, and pick the clip from the drop-down to scrub through it. If it looks right there, it will look right in game.
