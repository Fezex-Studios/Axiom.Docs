Tools

Asset & Character Pipeline#

The runtime side (how bodies, gear and animation work) is in Characters, gear & animation; import rules and folders in Art & assets. This page is the tool workflows.

A new NPC / monster model#

  1. FBX into Art/Creatures/ (Art/Creatures/Humanoid/ for a humanoid rig).
  2. Tools ▸ Axiom ▸ Art & Assets ▸ Make World Prefab From Selected Model → Art/Objects/Creatures/<Key>.prefab with a click capsule on the NPC layer, root motion off, registered as <Key> in WorldObjectPrefabs.
  3. Give it an Animator controller (Create Character Animator Controller works for creatures too: Speed, Attack, Hit, Die...).
  4. Content Studio ▸ NPC Templates: ModelType = <Key> (or the NPC wizard).
  5. Tools ▸ Axiom ▸ Server Exports ▸ NPC Collision ▸ Export so the server knows its body size (Server exports).
  6. Restart the World server.

A new mount#

  1. Name the FBX after the mount's ModelType (Mount_Horse.fbx) and put it in Art/Mounts/ (Generic rig, clips imported and looped). Check its size next to a character and fix Scale Factor before the next step.
  2. Make World Prefab From Selected Model → Art/Objects/Mounts/<Key>.prefab with a RiderSeat child, registered in WorldObjectPrefabs. If the key already exists, drag the new prefab onto that catalog entry instead.
  3. Select the prefab, Tools ▸ Axiom ▸ Characters & Gear ▸ Animation ▸ Create Mount Animator Controller (pick its SpeedMultiplier): a Speed blend tree from its Idle/Walk/Run clips, put on the prefab.
  4. Give the character controller's Ride state a humanoid riding clip, then open the prefab and place RiderSeat (the rider's feet go on it, so about the pose's hip height under the saddle).
  5. Ride forward and check both face away from the camera: a backwards horse is fixed on its model child (Rotation Y 180 and negate Position X/Z), a backwards rider on the clip (Root Transform Rotation Offset 180).
  6. Content Studio ▸ Mounts: ModelType = <Key> (and a whistle item, see Mounts and pets).

A new playable body#

  1. FBX into Art/Characters/ (imports as Humanoid).
  2. Make World Prefab From Selected Model (adds CharacterSockets), or build the prefab by hand: pivot at the feet, facing +Z, Animator.
  3. Dev Tools ▸ Characters & Races: drop it into the slot for Character_{Race}_{Gender}; Add missing sockets (from the Character Pipeline's socket list); Split body into parts (Head, Torso, Arms, Hands, Legs, Feet... so armour can hide what it covers). Bodies split by hand in Blender work too if meshes are named Body_Torso, *_Legs...
  4. If its bones are named differently from your gear's rig, add bone aliases in Characters & Races ▸ Pipeline (CharacterPipeline.asset).
  5. Wardrobe view: check every existing gear piece on the new body; add _Female / _Elf_Female prefab variants where skinned armour is on the wrong rig.

Guides: Characters, races and genders, Bring your own characters, Character customisation.

An animator controller#

Tools ▸ Axiom ▸ Characters & Gear ▸ Animation ▸ Create Character Animator Controller builds a controller with every parameter CharacterAnimator drives and the states wired, with empty motion slots:

  • Base layer: Locomotion blend tree on Speed (Idle/Walk/Run), Jump/Fall on Grounded, Swim, Ride (Mounted), Seated, Die → Dead, Revive back to locomotion.
  • Actions layer (full-body override; give it an upper-body Avatar Mask to cast while running): Attack, Cast (held while Casting), CastRelease, CastInterrupted, Hit, Crit, Miss.

Drop clips into the slots and it plays. For a per-ability animation, add a trigger named like Skills.AnimationParameter and a state for it. Upgrade Selected Animator Controller adds newer parameters/states to an older controller without touching assigned clips. Guide: Adding animations.

A weapon#

  1. Model grip at the origin, blade along +Y, edge +Z. Into Art/Gear/ (static). Prefab under Resources/Gear/....
  2. Create the item (Item wizard or Content Studio).
  3. Dev Tools ▸ Gear Workshop ▸ Fit: pick the item and a body, drop the prefab, slot MainHand, DrawnSocket MainHand, SheathSocket Back or HipLeft, adjust the offsets live in the Scene in both drawn and sheathed poses.
  4. Save for everyone → the item's GearVisuals row (database + patch).
  5. Export game data. Guide: Adding weapons.

A piece of armour#

  1. Skinned to the same skeleton as the bodies (bone names matching or aliased). Into Art/Gear/Skinned/.
  2. Gear Workshop: Attach Skinned, choose the body parts it hides (Torso | Arms for a chest piece).
  3. For a body that needs a different mesh, Save as variant (ChestPlate_Female beside ChestPlate) - no database change.
  4. Guide: Adding armor, worked example: Ranger gear walkthrough.

An outfit pack#

Tools ▸ Axiom ▸ Characters & Gear ▸ Import Outfit Pack… (Gear Workshop ▸ Outfits): a folder of FBX parts + textures becomes one HDRP material per outfit and one prefab per part under Art/Gear/Outfits, ready to assign as gear visuals.

  • Pieces replace the body and come in sets. Each piece sits inside the body, so it must hide every body part it covers. Where one piece only works with another (a sleeveless tunic + its sleeves; pants + boots), build the item from a copy of the pack's whole-outfit prefab with the other pieces switched off. The Quaternius Ranger tunic hides Torso, Shoulders, Arms, Hands (the male body has a separate Shoulders part).
  • Pants and boots: add the Pipeline part rules Lower Leg → Feet (both sides) and Split again, so pants hide hips to knee and boots knee down, in any combination.
  • Female versions are saved with Gear Workshop's Save as 'Female' variant (stored next to the base under its generated name). Changing the base prefab gives it a new name: save the variants again.
  • Normal maps from a Normals-UnrealEngine folder need Flip Green Channel, or the lighting comes out upside down.

Worked example: Ranger gear walkthrough, "Sets, not single pieces".

Icons#

Drop a PNG into Art/Resources/Icons/... named exactly as the item's icon_name (or the skill's/status's IconName, which may include subfolders: Skills/Axiom/Warrior/strike). No import settings needed. Imported DDS artwork can be mapped to existing names with Resources/UI/IconAliases.json; browse with Tools ▸ Axiom ▸ UI ▸ Imported DDS Icons.

Checks#

Tool Catches
Tools ▸ Axiom ▸ Art & Assets ▸ Asset Audit model keys used by the database with no prefab, wearable items with no look, body keys a race/gender would ask for, import problems
Tools ▸ Axiom ▸ Characters & Gear ▸ Check and Export Gear Visuals every gear visual row against its prefab; registers missing prefab keys, ready for the gamedata.bin export
Run Gear Binding Checks regression test: equips sample gear on the default body, checks bones, sockets and hidden parts bind
Gear Visuals (Database) edit one item's gear row directly
Dev Tools ▸ Characters & Races ▸ Wardrobe which variant each body would wear; skinned gear on the wrong rig
