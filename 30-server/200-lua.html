Lua Scripting#

Axiom has two Lua environments, both MoonSharp (Lua 5.2), both sandboxed and time-limited. (For compiled C# on the server, with hooks that change XP, damage, items or prices before they happen, see C# server plugins.)

Server Lua Client UI Lua
Runs in World server (Core/Lua) Unity client (Scripts/UI/Toolkit/Lua)
For game logic: rewards, events, chat commands, NPC dialogue, timed events UI addons: windows, bars, slash commands
Scripts Axiom.Server.World/Lua/Server/**/*.lua (copied next to the exe) Assets/AxiomMMOKit/Axiom.Client/Lua/DesignerScripts/UI/*.lua (packed into LuaUiScripts.asset)
Loaded once at World start (restart to reload) on entering the world, in name order; /lua reload in chat
Can read and change game state through the API read-only game state; can't act (no casting, moving, buying)
SDK LuaSDK/Server/ (README, library, examples, TEMPLATE) Lua/LuaSDK/Client/
API Lua API reference Lua API reference

Server Lua#

How it runs#

LuaEngine (Core/Lua/LuaEngine.cs), Eluna-style:

  1. At boot, PlayerManager.InitializeScripts() loads every .lua file in Lua/Server (and subfolders). Each runs its top level once, which is where it registers hooks, commands and timers. The log shows [LuaEngine] Loaded script: … or the error with file and line.
  2. Gameplay code fires events (PlayerManager.Fire*Event, LuaEngine.FireEvent); the engine calls the registered functions. No file is touched after boot.
  3. Sandbox (Preset_SoftSandbox): string, table, math, coroutine, os.time/os.clock. No io, os.execute, load/loadstring/dofile/require, network.
  4. Budget: each hook/command/timer call may run 200 000 instructions (HookInstructionBudget; a few ms), loading a file 5 000 000. Past that it's stopped and logged; a hook that overruns 3 times is switched off. A while true do end costs one budget, not the shard.
  5. Everything runs on the tick thread, so scripts can call any API safely.

The API in one screen#

-- events, by name (handler arguments are listed in the reference)
Server:On("OnKill", function(player, npcTemplateId) ... end)
Server:On("OnEnterZone", function(player, zoneId, zoneKey, previousZoneId) ... end)
-- or by id: Server:RegisterPlayerEvent(Events.OnKill, handler)

-- chat commands: ".name args" (the message isn't shown to anyone)
Server:RegisterCommand("where", function(player, args)
    local x, y, z = player:GetPosition()
    player:SendMessage(("%.0f, %.0f, %.0f in zone %d"):format(x, y, z, player:GetZoneId()))
end)

-- timers (ms)
local id = Server:Every(60000, function() ... end)
Server:After(5000, function() ... end)
Server:CancelTimer(id)

-- the player
player:GetName()  player:GetLevel()  player:GetCharacterId()  player:IsOnline()
player:GiveGold(copper)  player:TakeGold(copper)  player:GetGold()
player:GiveItem(itemId, count)  player:TakeItem(itemId, count)  player:CountItem(itemId)  player:HasItem(itemId, count)
player:Teleport(x, y, z)        -- y = 0: ground height
player:SendMessage(text)  player:SendAnnouncementMessage(text)  player:SendDialogue(speaker, text)
player:Kick(reason)
player:GetData(key)  player:SetData(key, value)        -- per character, survives restarts

-- the world
Server:Players()  Server:PlayerCount()  Server:FindPlayer(name)  Server:GetPlayer(networkId)
Server:Broadcast(text)  Server:Announce(text)
local npc = Server:SpawnNpc(templateId, x, 0, z)       -- fights and drops loot, never respawns
Server:NpcsNear(x, z, radius)   npc:IsAlive()  npc:GetHealth()  npc:Despawn()
Server:ItemName(id)  Server:NpcName(id)
Server:GetData(key)  Server:SetData(key, value)        -- shared, in Data/lua_data.json
Server:Log(msg)  Server:Warn(msg)  Server:Error(msg)  Server:Now()  Server:GetDateTime()

Saved data (GetData/SetData) is for small values (strings, numbers, booleans): counters, daily flags, high scores. It's written to Data/lua_data.json a few seconds after a change. Anything bigger or that must be transactional with the character belongs in a real component (Add a persisted field).

Events#

Every event has an id in Core/Lua/PlayerEvent.cs and a name in the global Events table: OnConnect, OnDisconnect, OnLevelUp, OnChat (return false to block), OnDeath, OnInteract, OnItemUse, OnHarvest, OnKill, OnEnterZone, OnDoodadUse, OnCraft, OnTheft, OnTradePackSold, OnTrade, OnPvpKill, OnCrime, OnSentenced, OnTerritoryCaptured, OnWorldEvent, OnTreasure, OnClimb, OnItemObtained, OnJuryVote, OnAchievement, OnSkillUse. Arguments: reference.

The same events drive quests and achievements (both listen to LuaEngine.EventFired), so a script, a quest and an achievement always agree on what happened.

A complete script: a timed world boss#

From LuaSDK/Server/examples/world_boss.lua-style logic:

-- Lua/Server/sunday_boss.lua
local BOSS = 90400
local X, Z = 2400, -1800
local alive = nil

local function spawnBoss()
    if alive and alive:IsAlive() then return end
    alive = Server:SpawnNpc(BOSS, X, 0, Z)
    if alive then Server:Announce("The Kraken rises off the eastern coast!") end
end

Server:Every(60 * 60 * 1000, function()                 -- check hourly
    if Server:GetDateTime():sub(12, 13) == "20" then    -- 20:00-20:59 server time
        spawnBoss()
    end
end)

Server:On("OnKill", function(player, templateId)
    if templateId == BOSS then
        Server:Broadcast(player:GetName() .. " struck the final blow on the Kraken!")
        player:GiveItem(90001, 10)
    end
end)

For a scheduled boss with rewards for everyone who fought, prefer a WorldEvents row (World events); use Lua for the custom touches.

Editor setup#

Install VS Code and the Lua extension (sumneko/LuaLS), open Axiom.Server.World/Lua/Server/. Its .luarc.json points at LuaSDK/Server/library, so Server:, player: and npc: autocomplete and Server:On(" lists every event with typed handler arguments. Copy LuaSDK/Server/TEMPLATE.lua to start.

Exposing a new function to Lua (C#)#

The bindings are plain C# classes registered as MoonSharp UserData:

Lua C#
Server Core/Lua/Bindings/LuaServerBinding.cs
player Core/Lua/Bindings/LuaPlayer.cs
npc Core/Lua/Bindings/LuaNpc.cs
services they reach Core/Lua/LuaWorld.cs

A public method is callable from Lua immediately. Example: let scripts read a player's honor.

// Core/Lua/Bindings/LuaPlayer.cs
/// <summary>Honor points (0 when offline).</summary>
public int GetHonor() => Session is { } s ? s.Pvp.Honor : 0;

Then document it in LuaSDK/Server/library/axiom_server.lua (so editors autocomplete it) and the SDK README:

---Honor points (0 when offline).
---@return integer
function Player:GetHonor() end

Rules for bindings: validate every argument (scripts are content, not trusted code), go through the same manager APIs C# uses (TryAddItem, not the inventory array), return simple types (numbers, strings, booleans, tables of them, LuaPlayer/LuaNpc), and never block.

A new event#

  1. Add the value to PlayerEvent (Core/Lua/PlayerEvent.cs).
  2. Fire it where it happens: _players.FireGameEvent(peer, PlayerEvent.OnFishCaught, fishItemId) (or add a typed Fire…Event helper on PlayerManager).
  3. Add it to axiom_server.lua (Events table, the AxiomEvent alias and an @overload with the handler's arguments).

Quests and achievements can then count it too.

Client UI Lua#

UI addons built from windows, labels, bars, buttons, item slots, inputs, with slash commands, timers and saved settings. Game state is read-only (that keeps addons from becoming bots).

-- Assets/AxiomMMOKit/Axiom.Client/Lua/DesignerScripts/UI/20_target_frame.lua
local w   = UI.Window("tf", "Target", 240, 0)
local nm  = w:Label("", "ac-h2")
local bar = w:Bar("#C9423A")

SDK.On("TargetChanged", function(id, name)
    if id == 0 then w:Close() else nm:SetText(name); w:Open() end
end)
UI.Every(0.2, function()
    if w:IsOpen() and Game.HasTarget() then
        bar:SetValue(SDK.Ratio(Game.TargetHealth(), Game.TargetMaxHealth()))
    end
end)
UI.Command("tf", function() w:Toggle() end)
  • Files load in name order; 000_axiom_sdk.lua (the SDK.* helpers and value-change events) is first.
  • /lua reload re-runs everything (in the editor); /lua lists what's loaded.
  • Styling uses USS classes from Resources/UI stylesheets (ac-h2, ac-muted, ac-small, ac-gold).
  • Builds pack the scripts automatically (LuaUiScriptPacker; manually: Tools ▸ Axiom ▸ UI ▸ Lua ▸ Pack Scripts).
  • To add to the API: public methods on LuaUiApi (UI), LuaGame (Game, keep it read-only) and LuaElement (Scripts/UI/Toolkit/Lua/LuaUiApi.cs), then document them in library/axiom_ui.lua.

The client also has LuaNetworkBinding (Networking/LuaNetworkBinding.cs) for scripted network hooks used by the UI layer. See UI.
