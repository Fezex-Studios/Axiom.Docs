CharacterSaveResult#

Name Value Notes
Saved 0 Written. CurrentSeq == the request's SaveSeq.
Stale 1 Not written: the database already holds this SaveSeq or a newer one. If CurrentSeq == the request's SaveSeq, this exact request was applied earlier (a retry after a lost answer) - i.e. success.
