Project Layout#

The generated code maps list every file with its summary: server code map, client code map.

Server solution (AxiomCore/, AxiomCore.slnx)#

src/
├── Shared/
│   ├── Axiom.Network/              netstandard2.1 - shared with the client (Assets/AxiomMMOKit/Plugins)
│   │   ├── Shared/Opcodes.cs       every C2W/W2C opcode
│   │   ├── Shared/ProtocolVersion.cs   the version number + its history
│   │   ├── Shared/PacketChannels.cs    which LiteNetLib channel each opcode uses
│   │   ├── Shared/Packets/         client <-> world packets (MessagePack); W2P/P2W persistence contracts; Staff (GM)
│   │   ├── Shared/Combat, Items, Inventory, Housing, Chat, Social...   rules both sides use
│   │   ├── Client/                 ClientPacketDispatcher, ClientPacketSender, IClientPacketHandler
│   │   └── Worldserver/            WorldserverPacketSender, IPacketHandler
│   ├── Axiom.Movement/             netstandard2.1 - shared: CharacterMotor, collision worlds, terrain,
│   │                               WorldGrid (512 m tiles), ZoneMap, movement netcode helpers
│   ├── Axiom.Navigation/           navmesh pages and baking (DotRecast)
│   └── Axiom.Plugins.Api/          the contract C# server plugins build against (C# server plugins guide)
├── Servers/
│   ├── Axiom.Server.World/         the game server
│   │   ├── Program.cs, Bootstrap/  host, config binding, NLog, EF factory
│   │   ├── Core/                   every gameplay system, one folder each (below)
│   │   ├── GameData/               EF entity classes for worldserver.db, one folder per family
│   │   ├── Migrations/             hand-written schema migrations (worldserver.db)
│   │   ├── SQL/patches/            content patches, NNN_name.sql (SQL/archived: old ones)
│   │   ├── Replication/            snapshot writer/codec, jump events
│   │   ├── Utils/Config, Utils/Database  config classes, WorldDataDbContext, GameDataPatchRunner
│   │   ├── Data/                   worldserver.db, world_collision/, terrain_data/, navmesh/, world/zones.aczmap,
│   │   │                           npc_collision.json, housing/, currency-shops.json
│   │   ├── Lua/Server/             server scripts (loaded at boot)
│   │   ├── LuaSDK/Server/          annotations + examples for script authors
│   │   └── appsettings.json (+ .Local.json, World.Performance.json), nlog.config
│   ├── Axiom.Server.Auth/          ASP.NET minimal API: Endpoints/ (login, register, sessions, worlds, game data,
│   │                               moderation), Services/ (tokens, BCrypt, throttling, world registry), Migrations/
│   ├── Axiom.Server.Persistence/   ASP.NET minimal API in Program.cs (+ Api/CommunityEndpoints.cs): characters,
│   │                               saves, mail, guilds, housing, doodads, shard state; Api/Models, Api/Data
│   │                               (PersistenceDbContext), Migrations/, SQL/ (hand-runnable scripts per feature)
│   └── Axiom.Server.Auction/       auction house: Data/, Models/, Services/ (mail dispatch)
├── Tools/
│   ├── Axiom.LoadTest/             bot fleet; presets/, results/, scripts/
│   └── Axiom.Tools.NavBake/        command-line navmesh baker
├── Plugins/Axiom.SamplePlugin/     an example server plugin
└── Tests/Axiom.Server.World.Checks/   `dotnet run`: checks for missions, guild shop, recruitment, item UIDs, area targeting...
scripts/                            .bat build/start helpers, Build.Docs.bat, MySQL helpers; docs/ = the docs generator
docs/                               this documentation as Markdown (How these docs are built)
Axiom-Docs/                         the generated site

Unity client (Axiom.Client/Assets/)#

Everything that ships is under Assets/AxiomMMOKit/. Editor paths come from AxiomAssetPaths (Kit, Client, Plugins), so moving the root folder is a change in that one file plus CharacterPipeline.AssetPath and LuaUi.ScriptFolder (runtime code can't see the editor class).

Assets/
├── AxiomMMOKit/                     the kit's one root folder: everything that ships (Asset Store rule)
│   ├── Axiom.Client/                game code + content (assembly Axiom.Client)
│   │   ├── Networking/              ClientNetwork, W2CHandlers/, C2WSenders/, WorldLoader, spawn queue, snapshots,
│   │   │                            movement prediction, world entry gate, selection flow, world directory
│   │   ├── Movement/                LocalCharacterMotor, input actions, hotkeys, schemes, UnityCollisionWorld
│   │   ├── Scripts/
│   │   │   ├── GameData/            gamedata.bin bootstrap, crypto, format, repositories, icons
│   │   │   ├── Gameplay/            characters, combat, interaction, doodads, mounts, housing, quests, trade, social...
│   │   │   ├── UI/                  Toolkit/ (framework, windows, maps, shops, Lua UI), HUD pieces, chat, inventory
│   │   │   ├── World/               Streaming/ (WorldStreamer, FloatingOrigin, HLOD), Zones/, prefab registry, markers
│   │   │   └── Exploration/, Pvp/, Staff/, ClientConfig/
│   │   ├── World/                   scenes: server_select, main_world, Tiles/<area>/tile_X_Z
│   │   ├── Doodads/, Entities/, Housing/, Furniture/    prefabs
│   │   ├── Content/                 NpcCollisionProfiles.asset
│   │   ├── Lua/                     DesignerScripts/UI (Lua UI addons), LuaSDK/Client
│   │   ├── db/                      legacy client content DB and Game Data tab outputs
│   │   └── Art/                     models, textures, animations, Resources/
│   ├── Editor/                      the Axiom editor suite (Core, Hub, DevTools, ContentStudio, Create, Characters,
│   │                                AssetPipeline, ServerExports, World, UI, Validation, Project)
│   ├── Plugins/                     Axiom.Network.dll, Axiom.Movement.dll, MoonSharp
│   ├── ThirdParty/                  LiteNetLib, MessagePack (+ its analyzer), sqlite-net + SQLitePCLRaw
│   └── link.xml                     keeps types IL2CPP would strip
├── StreamingAssets/                 GameData/gamedata.bin, World/MovementCollision, World/NpcCollision, World/zones.aczmap
│                                    (Unity only reads it here; everything in it is generated by the tools and servers)
└── Settings/                        your own project's HDRP settings and Build Profiles: not part of the kit

Where new things go#

You're adding Put it in
A packet Axiom.Network/Shared/Packets/C2W|W2C, opcode in Opcodes.cs (recipe)
A server system Axiom.Server.World/Core/<System>/, registered in WorldServer (recipe)
A content table migration in Migrations/, entity in GameData/<Family>/, DbSet in WorldDataDbContext (recipe)
Content rows Content Studio → SQL/patches/NNN_content_*.sql
Saved per-character state a component in Core/Players/Components, DTO in Axiom.Network, table in Persistence (recipe)
A client handler / sender Networking/W2CHandlers, Networking/C2WSenders (+ register)
Client state a static state class next to its gameplay folder (Scripts/Gameplay/<System>/<System>State.cs)
A window / HUD piece Scripts/UI/Toolkit/Windows/, UiHudComponent subclasses (recipe)
An editor tool Assets/AxiomMMOKit/Editor/<Area>/ with [MenuItem] + [AxiomTool], or an IDevToolsTab
Art Art/<Characters|Creatures|Gear|Props|...>/ (the folder sets import rules), runtime-loaded assets under Art/Resources
A server Lua script Axiom.Server.World/Lua/Server/
A Lua UI addon Assets/AxiomMMOKit/Axiom.Client/Lua/DesignerScripts/UI/ (then Pack Scripts)
