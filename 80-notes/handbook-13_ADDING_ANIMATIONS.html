13. Adding Animations#

Three jobs, in the order you'll meet them: set up the player's animator once, give an ability its own animation, and animate an NPC.

For Unity animation basics and the exact clip for every state, see CHARACTER_ANIMATION_README.md (Tools > Axiom > Help > Reference).

How it works (one minute)#

The game never plays clips by name. It sets parameters on the character's Animator (Speed, Grounded, Attack, Casting, Dead…) and the Animator Controller decides which clip that means. So adding animation is always: a clip, a state in the controller, and a transition on the right parameter.

Parameter Type Set when
Speed float moving (m/s; 5 = running)
LocomotionDirection float 1 forward, −1 backpedalling
Grounded, Swimming, Flying, Mounted, Seated, InCombat bool the state you'd expect
Jump trigger jumping
Attack trigger a melee swing (the default for every ability)
Casting / CastRelease / CastInterrupted bool / trigger / trigger a cast bar running, the spell going off, being interrupted
Hit, Crit, Miss trigger being hit, critically hit, dodging
Die / Dead / Revive trigger / bool / trigger dying, staying dead, coming back
SkillId int the id of the ability being used (for branching on abilities)
your own name trigger an ability whose AnimationParameter is that name

Part A: The player animator (once per project)#

  1. Clips. Put your animation FBX (e.g. Universal Animation Library) in Assets/AxiomMMOKit/Axiom.Client/Art/Animations/. Select it: Rig tab = Humanoid, Apply.
  2. The controller. Tools > Axiom > Characters & Gear > Animation > Create Character Animator Controller. It creates Assets/AxiomMMOKit/Axiom.Client/Art/Animations/Controllers/AxiomCharacter.controller with every parameter and state wired, but no clips.
  3. Put it on every body. Open each body prefab (Dev Tools > Characters & Races > Bodies shows them). Select the child with the Animator: Controller = AxiomCharacter, Apply Root Motion off.
  4. Upper-body mask. Project window > Create > Avatar Mask, name it UpperBody. Under Humanoid, click the legs, feet and root so they turn red. In the Animator window > Layers > gear on Actions > Mask = UpperBody. This lets you swing a sword while running.
  5. Fill the states. Click a state, drag a clip into Motion. Start with these four and test:
State Layer Clip (UAL names) Loop
Locomotion (blend tree) Base Idle / Walk / Jog / Sprint at thresholds 0 / 1.6 / 5 / 8 on
Attack Actions Sword_Attack off
Die Base Death01 off
Dead Base Death01 off

Empty states are skipped, so fill the rest when you're ready (the reference guide lists every one). 6. Press Play and walk, run, attack.

Female and race bodies: with a Humanoid rig, the same controller and clips work on every body. If a body needs its own feel, use an Animator Override Controller (Part C, step 5) instead of copying the controller.

Made the controller before 10 Oct 2026? Select it and run **Animation

Upgrade Selected Animator Controller**. It adds new parameters and keeps your clips.

Part B: An ability's own animation#

Example: give the skill Strike its own swing instead of the default Attack.

  1. The skill. Content Studio (Ctrl+Alt+E) > Skills > Strike. Set AnimationParameter to Strike. Ctrl+S. Restart the World server.
  2. The clip. Select it in the Project window. Animation tab: Loop Time off (it plays once). Apply.
  3. The parameter. Open AxiomCharacter.controller in the Animator window (Window > Animation > Animator). Parameters > + > Trigger, named exactly Strike.
  4. The state. Select the Actions layer (upper body) or Base Layer (whole body, e.g. a spin). Right-click > Create State > Empty, name it Strike, drag the clip into Motion.
  5. The way in. Right-click Any State > Make Transition > click Strike. On the arrow: Has Exit Time off, Duration 0.05, Can Transition To Self off, Conditions: Strike.
  6. The way out. Right-click Strike > Make Transition > Empty (or Locomotion on the Base Layer). On the arrow: Has Exit Time on, Exit Time 0.9, Duration 0.1, no conditions.
  7. Test. Play, use Strike, and watch the Animator window with your character selected: the Strike box lights up.
You see Fix
The normal Attack instead AnimationParameter empty, server not restarted, or the name doesn't match the trigger exactly (the game falls back to Attack)
Nothing; the box never lights the Any State arrow has no Strike condition, or the parameter isn't a Trigger
The box lights but nothing moves Motion is None, or the Actions layer weight is 0
Frozen in the end pose no way-out transition (step 6)

Part C: An NPC#

Humanoid NPC (guards, bandits, orcs on a human rig):

  1. FBX into Assets/AxiomMMOKit/Axiom.Client/Art/Creatures/Humanoid/. Rig: Humanoid, Apply.
  2. Select it > Tools > Axiom > Art & Assets > Make World Prefab From Selected Model. You get a prefab in Prefabs/World/Creatures/ with a click collider and root motion off, registered under its file name as a model key.
  3. Open the prefab: the blue arrow should point out of the chest. If not, rotate the child 180°.
  4. On the model child's Animator: Controller = AxiomCharacter.
  5. Want different clips? Create > Animator Override Controller, set its Controller to AxiomCharacter, replace only the clips you want different, and put it on the Animator instead.
  6. Content Studio > NpcTemplates: set the NPC's ModelType to the model key. Commit, restart the World server.

Monster (wolf, spider: not human-shaped): Rig Generic; make its own small controller with the same parameter names (Speed, Attack, Hit, Die, Dead). The game sets those parameters on any Animator.

Vendors and quest givers just need an idle: put an idle clip in Locomotion, or a controller with one state.

Checklist#

  • [ ] Clips imported as Humanoid (or Generic for creatures), attacks not looping
  • [ ] Controller on every body's Animator, Apply Root Motion off
  • [ ] Upper-body mask on the Actions layer
  • [ ] Ability: AnimationParameter = trigger name; state with Motion; in and out transitions
  • [ ] World server restarted after Skills changes
