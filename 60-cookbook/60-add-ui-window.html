Cookbook (How-To)

Add a UI Window or HUD Widget#

Framework reference: User interface. Here we add a Playtime window (total time played, next reward) and a tiny HUD clock, fed by a server packet W2CPlaytimeState { TotalMinutes, NextRewardMinutes } that you'd add with Add a packet and send from the playtime service (Add a server system) on login and every minute.

W2CPlaytimeState ─► W2CPlaytimeStateHandler ─► PlaytimeState (cache + Changed event)
                                                   ├─► PlaytimeWindow   (opened from the menu / a key)
                                                   └─► PlaytimeClockHud (always on)

1. The state class#

Assets/AxiomMMOKit/Axiom.Client/Scripts/Gameplay/Playtime/PlaytimeState.cs:

using System;

namespace Axiom.Client.Axiom.Client.Scripts.Gameplay.Playtime
{
    /// <summary>Your playtime as the server last said. Handlers write, UI reads. Static: survives scene loads.</summary>
    public static class PlaytimeState
    {
        public static long TotalMinutes { get; private set; }
        public static int NextRewardMinutes { get; private set; }
        public static bool Known { get; private set; }
        public static event Action Changed;

        public static void Apply(long total, int next)
        {
            TotalMinutes = total; NextRewardMinutes = next; Known = true;
            Changed?.Invoke();
        }

        public static void Reset() { TotalMinutes = 0; NextRewardMinutes = 0; Known = false; Changed?.Invoke(); }
    }
}

Call PlaytimeState.Reset() next to the other per-world resets in ClientNetwork (search for MailNoticeState.Reset, three places), so a character switch doesn't show the previous character's time.

2. The handler#

public class W2CPlaytimeStateHandler : IClientPacketHandler
{
    public void Handle(NetPacketReader reader)
    {
        var p = MessagePackSerializer.Deserialize<W2CPlaytimeStatePacket>(reader.GetRemainingBytesMemory());
        PlaytimeState.Apply(p.TotalMinutes, p.NextRewardMinutes);
    }
}
// ClientNetwork.RegisterHandlers():
dispatcher.Register(Opcodes.W2CPlaytimeState, new W2CPlaytimeStateHandler());

3. The window#

Assets/AxiomMMOKit/Axiom.Client/Scripts/UI/Toolkit/Windows/PlaytimeWindow.cs:

using Axiom.Client.Axiom.Client.Scripts.Gameplay.Playtime;
using UnityEngine;
using UnityEngine.UIElements;

namespace Axiom.Client.Axiom.Client.Scripts.UI.Toolkit.Windows
{
    public sealed class PlaytimeWindow : ToolkitWindow
    {
        public static readonly PlaytimeWindow Instance = new PlaytimeWindow();
        private Label _total, _next;
        private UiBar _bar;

        private PlaytimeWindow() : base("playtime", "Playtime", 300, 0) { }

        protected override void Build(VisualElement content)
        {
            var sheet = Resources.Load<StyleSheet>("UI/Playtime/Playtime");     // optional feature sheet
            if (sheet != null) Window.styleSheets.Add(sheet);
            Window.AddToClassList("axiom-playtime");

            var row = Ui.Row(content);
            Ui.Label(row, "Time played", "ac-muted", "ac-grow");
            _total = Ui.Label(row, "", "ac-gold");

            _next = Ui.Label(content, "", "ac-text-wrap");
            _bar = new UiBar(new Color(0.85f, 0.7f, 0.3f));
            content.Add(_bar);
        }

        protected override void OnOpened() { PlaytimeState.Changed += Render; Render(); }
        protected override void OnClosed() => PlaytimeState.Changed -= Render;

        private void Render()
        {
            if (!PlaytimeState.Known) { _total.text = "…"; _next.text = ""; return; }
            long h = PlaytimeState.TotalMinutes / 60, m = PlaytimeState.TotalMinutes % 60;
            _total.text = $"{h} h {m} min";
            int left = PlaytimeState.NextRewardMinutes;
            _next.text = left > 0 ? $"Next reward in {left} min." : "No more rewards today.";
            _bar.Value = left > 0 ? 1f - Mathf.Clamp01(left / 30f) : 1f;
        }
    }
}

Resources/UI/Playtime/Playtime.uss (under Art/Resources):

.axiom-playtime .ac-gold { font-size: 16px; -unity-font-style: bold; }
.axiom-playtime .ac-bar  { margin-top: 6px; height: 10px; }

Use the existing ac-* classes first; a feature sheet should only adjust its own window (scope selectors under the window's class).

4. Open it#

From the game menu: add a case to UiGameMenu.Dispatch (Scripts/UI/Toolkit/UiGameMenu.cs):

                case "playtime": PlaytimeWindow.Instance.Toggle(); break;

A hotkey (rebindable): add _playtime = Add("Playtime", "<Keyboard>/semicolon", null); and a property in GameHotkeys, include it in All, and in WorldUIManager's hotkey block:

            if (GameHotkeys.Pressed(GameHotkeys.TogglePlaytime)) UiGameMenu.Dispatch("playtime");

That block already ignores keys while typing in chat, while a blocking window is open and before entering the world. Escape closes the window (it's opened through WorldUIManager).

5. A HUD widget#

Assets/AxiomMMOKit/Axiom.Client/Scripts/UI/Playtime/PlaytimeClockHud.cs:

using Axiom.Client.Axiom.Client.Scripts.Gameplay.Playtime;
using Axiom.Client.Axiom.Client.Scripts.UI.Toolkit;
using UnityEngine.UIElements;

public sealed class PlaytimeClockHud : UiHudComponent
{
    private Label _label;
    protected override string ClassName => "axiom-playtime-clock";
    protected override void Build()
    {
        _label = Ui.Label(Root, "", "ac-small", "ac-muted");
        Root.RegisterCallback<ClickEvent>(_ => UiGameMenu.Dispatch("playtime"));
        PlaytimeState.Changed += Render; Render();
    }
    protected override void OnDestroy() { PlaytimeState.Changed -= Render; base.OnDestroy(); }
    private void Render() => _label.text = PlaytimeState.Known ? $"⌛ {PlaytimeState.TotalMinutes / 60}h" : "";
}

Create it with the HUD in UiBootstrap.Loaded (the main_world branch): UiSession.Get<PlaytimeClockHud>();. Position it in USS:

.axiom-playtime-clock { position: absolute; right: 220px; top: 8px; }

6. Check#

  • Play, open with the key and the menu, resize the game view (the root gets axiom-compact under 1200 px).
  • Tools ▸ Axiom ▸ Validation ▸ UI ▸ Window Geometry and Toolkit Audit; Run All Checks before committing.
  • Switch character: the window must not show the previous character's time (that's the Reset).

Making it a Lua addon instead#

If the data is already available to Lua (Game.*, SDK.On), a designer can do the window in Lua with no C# build - see Lua UI addons. New data needs C# to expose it to the Lua API (LuaUiApi).
