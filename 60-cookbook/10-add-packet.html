Cookbook (How-To)

Add a Packet (end to end)#

We'll build Inspect: you target another player, type /inspect, and a window shows their name, level and visible gear. It touches every layer:

client: /inspect ─► C2WInspectRequestPacket ─► World: C2WInspectRequestHandler
                                                   checks: in world, target is a player you can see
client: InspectWindow ◄─ W2CInspectResultHandler ◄─ W2CInspectResultPacket

Background: Networking & packets, Client networking. Every packet that exists is listed in the packet reference.

1. Opcodes (src/Shared/Axiom.Network/Shared/Opcodes.cs)#

Append at the end of enum Opcodes : ushort, with explicit numbers. Never renumber or reuse a number.

        C2WPatronClaim  = 180, // ...
        W2CPatronState  = 181, // ...

        // Inspect (protocol 45)
        C2WInspectRequest = 182, // C2W: show me this player's name, level and gear
        W2CInspectResult  = 183, // W2C: the answer to C2WInspectRequest
    }

2. Packet classes#

src/Shared/Axiom.Network/Shared/Packets/C2W/C2WInspectRequestPacket.cs:

using MessagePack;

namespace Axiom.Network.Shared.Packets.C2W
{
    /// <summary>Opcode 182: inspect another player (by network id).</summary>
    [MessagePackObject]
    public class C2WInspectRequestPacket
    {
        [Key(0)] public int NetworkId;
    }
}

src/Shared/Axiom.Network/Shared/Packets/W2C/W2CInspectResultPacket.cs:

using System;
using MessagePack;

namespace Axiom.Network.Shared.Packets.W2C
{
    /// <summary>Opcode 183: what you see when you inspect someone.</summary>
    [MessagePackObject]
    public class W2CInspectResultPacket
    {
        [Key(0)] public int NetworkId;
        [Key(1)] public string Name = "";
        [Key(2)] public int Level;
        [Key(3)] public int ClassId;
        /// <summary>Item ids by EquipSlot (index = slot), visible slots only, 0 = nothing.</summary>
        [Key(4)] public int[] Gear = Array.Empty<int>();
    }
}

Rules for packet classes:

  • [MessagePackObject] with integer [Key(n)] on every field. Keys are the wire format: append new keys, never reuse or renumber one.
  • Give arrays and strings non-null defaults.
  • Only send what the client needs and may know. Never trust anything in a C2W packet beyond "what the player asked for".

3. Channel and rate limit#

Channel (Shared/PacketChannels.cs): anything not listed travels on World (0), ordered with spawns and combat. Windows and lists that may be large go on Bulk. An inspect result is small; leave it on World. (To use Bulk: add case Opcodes.W2CInspectResult: to the Bulk list.)

Rate limit (Axiom.Server.World/Core/Networking/PacketRateLimiter.cs): the default is 10/s with a burst of 20. A player won't inspect more than once a second, so tighten it:

            // Inspect (protocol 45)
            [Opcodes.C2WInspectRequest]          = new(1f, 3f),

A packet over its limit is dropped silently before the handler runs; a peer that keeps flooding is disconnected.

4. Protocol version (Shared/ProtocolVersion.cs)#

Changing what's on the wire means a new protocol: old clients must be refused at connect rather than misread packets.

    ///  45  2026-10-27: Inspect. C2WInspectRequest (182) and W2CInspectResult (183).
    public static class ProtocolVersion
    {
        public const int Current = 45;
        public const string ConnectionKey = "Axiom/45";

Also bump Program.SupportedProtocol in Axiom.LoadTest once you've checked the bots don't use anything that changed.

5. The server handler#

src/Servers/Axiom.Server.World/Core/Packets/C2WHandlers/C2WInspectRequestHandler.cs:

using Axiom.Network.Shared;
using Axiom.Network.Shared.Packets.C2W;
using Axiom.Network.Shared.Packets.W2C;
using Axiom.Network.Worldserver;
using Axiom.Server.World.Core.Managers;
using Axiom.Server.World.Core.Packets.W2CSenders;
using LiteNetLib;
using MessagePack;

namespace Axiom.Server.World.Core.Packets.C2WHandlers;

/// <summary>Protocol 45: inspect another player you can see.</summary>
[PacketOpcode(Opcodes.C2WInspectRequest)]
public sealed class C2WInspectRequestHandler : IPacketHandler
{
    private readonly PlayerManager _players;

    // Constructor parameters come from the ServiceContainer (WorldServer.RegisterServices).
    public C2WInspectRequestHandler(PlayerManager players) => _players = players;

    public void Handle(NetPeer peer, NetPacketReader reader)
    {
        var request = MessagePackSerializer.Deserialize<C2WInspectRequestPacket>(reader.GetRemainingBytesMemory());

        // 1. The asker must be in the world.
        if (!_players.TryGetSession(peer, out var me) || me.NetworkId is not int myId) return;

        // 2. The target must be a player who is in the world...
        if (!_players.TryGetPeer(request.NetworkId, out var targetPeer) ||
            !_players.TryGetSession(targetPeer, out var target) || target.NetworkId == null)
        {
            W2CInteractDeniedPacketSender.Send(peer, "That player isn't here.");
            return;
        }

        // 3. ...that the asker can actually see (no inspecting across the map by guessing ids).
        if (request.NetworkId != myId && !_players.Interest.IsKnown(myId, request.NetworkId))
        {
            W2CInteractDeniedPacketSender.Send(peer, "Too far away to inspect.");
            return;
        }

        W2CInspectResultPacketSender.Send(peer, target);
    }
}

The dispatcher finds the handler by its [PacketOpcode] attribute - no registration. Handlers run on the tick thread, so they may read and change game state directly. If you need something that isn't registered in WorldServer.RegisterServices, register it there.

Never await in a handler and then touch game state. If you must call another service (Persistence, Auction), capture ids, await, then hop back with _players.EnqueueAction(() => { ... }) and re-resolve the peer inside (threading rule).

6. The server sender#

src/Servers/Axiom.Server.World/Core/Packets/W2CSenders/W2CInspectResultPacketSender.cs:

using Axiom.Network.Shared;
using Axiom.Network.Shared.Packets.W2C;
using Axiom.Network.Worldserver;
using Axiom.Server.World.Core.Managers;
using LiteNetLib;

namespace Axiom.Server.World.Core.Packets.W2CSenders
{
    public static class W2CInspectResultPacketSender
    {
        public static void Send(NetPeer peer, PlayerSession target)
        {
            WorldserverPacketSender.SendPacket(peer, Opcodes.W2CInspectResult, new W2CInspectResultPacket
            {
                NetworkId = target.NetworkId ?? 0,
                Name      = target.Name ?? "",
                Level     = target.Level,
                ClassId   = target.ClassId,
                Gear      = PlayerAppearance.GearOf(target),   // visible slots only - the same rule as spawns
            });
        }
    }
}

WorldserverPacketSender.SendPacket writes the opcode + MessagePack body and sends reliable-ordered on the opcode's channel. For many recipients use ReplicationManager.Broadcast(opcode, packet, peers) (serialises once).

7. Build the shared DLL and copy it to the client#

cd src/Shared/Axiom.Network && dotnet build -c Release
# copy bin/Release/netstandard2.1/Axiom.Network.dll to <client>/Assets/AxiomMMOKit/Plugins/

Then build and restart the World server. Unity: Tools ▸ Axiom ▸ Server Exports ▸ Validate Netcode Build should be green.

8. The client sender#

Assets/AxiomMMOKit/Axiom.Client/Networking/C2WSenders/C2WInspectSenders.cs:

using Axiom.Network.Client;
using Axiom.Network.Shared;
using Axiom.Network.Shared.Packets.C2W;
using LiteNetLib;

namespace Axiom.Client.Axiom.Client.Networking.C2WSenders
{
    public static class C2WInspectRequestSender
    {
        public static void Send(NetPeer peer, int networkId)
        {
            if (peer == null || networkId == 0) return;
            ClientPacketSender.SendPacket(peer, Opcodes.C2WInspectRequest, new C2WInspectRequestPacket { NetworkId = networkId });
        }
    }
}

9. The client handler and registration#

Assets/AxiomMMOKit/Axiom.Client/Networking/W2CHandlers/W2CInspectHandlers.cs:

using Axiom.Client.Axiom.Client.Scripts.UI.Toolkit.Windows;
using Axiom.Network.Client;
using Axiom.Network.Shared.Packets.W2C;
using LiteNetLib;
using MessagePack;

namespace Axiom.Client.Axiom.Client.Networking.W2CHandlers
{
    /// <summary>Opcode 183: the answer to /inspect.</summary>
    public class W2CInspectResultHandler : IClientPacketHandler
    {
        public void Handle(NetPacketReader reader)
        {
            var packet = MessagePackSerializer.Deserialize<W2CInspectResultPacket>(reader.GetRemainingBytesMemory());
            InspectWindow.Instance.Present(packet);       // main thread: UI is fine here
        }
    }
}

In ClientNetwork.RegisterHandlers() add:

dispatcher.Register(Opcodes.W2CInspectResult, new W2CInspectResultHandler());

Forgetting this line is the #1 mistake: the packet is dropped with a message written by Console.WriteLine inside the DLL, which the Unity console doesn't show.

10. The window and the command#

The window is the InspectWindow from User interface. The trigger: add a case to Scripts/Gameplay/Social/SocialCommands.TryRun (chat slash commands):

                case "/inspect":
                    if (Combat.CombatClient.TargetId != 0 && !IsNpc(Combat.CombatClient.TargetId))
                        C2WInspectRequestSender.Send(peer, Combat.CombatClient.TargetId);
                    else feedback = "Target a player first, then type /inspect.";
                    return true;

(and mention /inspect in its Help string).

11. Test#

  1. Start Persistence, Auth, World (Server Control ▸ Start All).
  2. Two clients (ParrelSync clone or a build), two characters, stand next to each other.
  3. Target the other player, /inspect → the window shows their gear.
  4. Walk out of view range (> 85 m) and try again → "Too far away to inspect."
  5. Watch the World log for exceptions; on the client, a "Could not read W2CInspectResult" error means the client DLL is older than the server's.
