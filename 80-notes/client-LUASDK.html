Feature note, kept next to the code it describes. Source: Assets/AxiomMMOKit/Axiom.Client/Lua/LuaSDK/Client/README.md

Axiom Client UI Lua SDK#

Build your own UI in Lua: windows, bars, buttons, item slots, text boxes, slash commands and timers, that react to your character and target and remember settings. Scripts run in the client's MoonSharp Lua (Lua 5.2), sandboxed and time-limited.

Contents#

Path What
README.md This guide and the full API reference
library/axiom_ui.lua Editor definitions: autocomplete and type checking (not loaded by the game)
examples/ Complete scripts: target frame, gold tracker, notes, low-health warning
TEMPLATE.lua A starting point
../../DesignerScripts/UI/000_axiom_sdk.lua The SDK helpers (SDK.*), loaded before every other UI script

Where scripts go#

Every .lua file in Assets/Axiom.Client/Lua/DesignerScripts/UI/ loads when you enter the world, in name order (000_axiom_sdk.lua first, which is why it's named that way). Builds pack them in automatically (LuaUiScriptPacker).

In the editor, type /lua reload in chat to re-run all scripts after an edit (windows close, commands and timers are reset), and /lua to list what's loaded. Errors go to the Unity Console with the file and line.

Editor setup (autocomplete)#

  1. Install VS Code and the Lua extension (by sumneko / LuaLS).
  2. Open the folder Assets/Axiom.Client/Lua/DesignerScripts/UI/. Its .luarc.json points the extension at this SDK's library/, so UI., Game., SDK. and every element (w:) autocomplete, and SDK.On(" lists each event with its handler arguments.

(The .luarc.json path assumes DesignerScripts and LuaSDK both sit in Assets/Axiom.Client/Lua/. If you move either, change workspace.library in that file.)

A first window#

local w = UI.Window("hello", "Hello", 260, 0)          -- id, title, width, height (0 = fit)
local label = w:Label("Hi " .. Game.Name(), "ac-h2")
local bar = w:Bar("#C9423A")
w:Button("Close", function() w:Close() end)

SDK.On("HealthChanged", function(hp, max)
  bar:SetValue(SDK.Ratio(hp, max)):SetText(hp .. " / " .. max)
end)

UI.Command("hello", function(args) w:Toggle() end)   -- /hello in chat

Rules of the sandbox#

  • Lua 5.2 (MoonSharp). No // (use math.floor(a / b)), no goto.
  • No io, os.execute, network or file access. string, table, math, coroutine, pcall and print (to the Unity Console) are there.
  • Time limit: each callback (button, timer, command, event) may run 200,000 Lua instructions; loading a script 5,000,000. Past that it's stopped and logged.
  • Read-only game state. UI scripts can read your character and target and control the UI, but can't act in the game (cast, move, buy). That keeps addons from being bots.
  • Keep timers cheap: refresh only while your window is open (if w:IsOpen() then ... end).
  • Money is in copper: 10000 = 1g. SDK.FormatGold(copper) gives "1g 2s 3c".

Styling#

classes arguments take USS classes from Assets/Axiom.Client/Resources/UI/ stylesheets, for example ac-h2 (heading), ac-muted (grey), ac-small, ac-gold. Separate several with spaces: "ac-muted ac-small". Colours are "#RRGGBB".

API reference#

UI#

Function Does
UI.Window(id, title, width, height) -> Window A window (height 0 = fit content). Starts closed
UI.Open(id) / UI.Close(id) / UI.Toggle(id) Any window by id, built-in ones too
UI.Command(name, fn(args)) /name args in chat runs it
UI.Every(seconds, fn) -> Timer / UI.After(seconds, fn) -> Timer Repeat / once; timer:Stop()
UI.SetScale(0.75 .. 1.5) The whole UI's scale
UI.Print(text) A line in your own chat (colour/bold/italic tags work)
UI.SaveVar(key, value) / UI.LoadVar(key) Saved settings: per character, on this computer; strings, numbers, booleans

Game (read-only)#

Function Returns
Game.Name(), Level(), Gold() (copper)
Game.Health(), MaxHealth(), Mana(), MaxMana(), Labor(), LaborMax()
Game.Count(itemId), Game.ItemName(itemId) Items in your bag; an item's name
Game.TargetId() (0 = none), HasTarget(), TargetName(), TargetHealth(), TargetMaxHealth() Your target

Elements#

Builders (add a child, return it): Label(text, classes), Button(text, fn, classes), Input(label, value, changed(text)), Row(classes), Column(classes), Box(classes), Scroll(classes), Divider(), Bar(color), Slot(itemId, count).

Changers (return the element, so they chain): SetText, SetValue(0..1), SetItem(id, count), SetColor("#hex"), AddClass, RemoveClass, Show, Hide, Clear, Enabled(bool), Width(px), Height(px), Grow(n), OnClick(fn), Tooltip(text). GetText() reads a label or input.

A Window is an element plus Open(), Close(), Toggle(), IsOpen(), SetTitle(t), OnClose(fn).

SDK helpers (000_axiom_sdk.lua)#

Function Does
SDK.On(event, fn) -> fn / SDK.Off(event, fn) React when a value changes (checked 5x a second)
SDK.FormatGold(copper) "1g 2s 3c"
SDK.Ratio(a, b) a/b, or 0 when b is 0 (for bars)
SDK.Clamp(v, lo, hi)
SDK.Load(key, default) UI.LoadVar with a fallback
Event Handler arguments
HealthChanged (health, maxHealth)
ManaChanged (mana, maxMana)
GoldChanged (gold, previous)
LevelChanged (level, previous)
LaborChanged (labor, maxLabor)
TargetChanged (targetId, targetName) - 0, "" when cleared

A handler that errors is logged and skipped; the others still run.

Examples (examples/)#

File Shows
target_frame.lua /tf: target name and live health bar
gold_tracker.lua /gold: gold earned this session and all time (saved)
notes.lua /notes: a notepad that remembers what you type
low_health_warning.lua A chat warning below 30% health - no window at all

To try one, copy it into Assets/Axiom.Client/Lua/DesignerScripts/UI/ and /lua reload.

For engine developers: adding to the SDK#

The tables are C# classes in Scripts/UI/Toolkit/Lua/LuaUiApi.cs (UI = LuaUiApi, Game = LuaGame, elements = LuaElement), registered in LuaUi.Reload. A public method there is callable from Lua at once. Keep Game read-only. New value-change events can be added to 000_axiom_sdk.lua (one watch(...) line). Then update library/axiom_ui.lua and this README.
