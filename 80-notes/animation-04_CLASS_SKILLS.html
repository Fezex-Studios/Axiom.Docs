Animation Handbook

04 Class skills#

How a skill picks its animation#

Every ability is a row in Content Studio > Skills. The row's AnimationParameter decides what plays:

AnimationParameter What plays
Empty A weapon ability fires the shared Attack trigger; a spell fires CastRelease when it goes off
A trigger name (e.g. ShieldBash) That trigger fires once when the ability goes off: a one-shot swing or release
A bool name (e.g. Channel_Heal) That bool is held true for the whole cast or channel and cleared when it ends, is cancelled or is interrupted: a looping cast or channel

The game looks at the parameter's type in your controller: make it a Trigger for one-shots and a Bool for anything that lasts. If the controller has no parameter with that exact name, the game falls back to the shared Attack / CastRelease.

Around every cast with a bar, these also fire automatically: - Casting (bool) is true for the length of the cast bar. - CastRelease (trigger) fires when it completes; CastInterrupted (trigger) if it's stopped. - InCombat goes true, so weapons are drawn.

The three kinds of skill animation#

Kind Example Parameter States
Instant strike Shield Bash, Backstab Trigger ShieldBash One state with the swing clip, back to idle on exit time
Cast then release Fireball (2 s cast) Trigger Fireball (or rely on Casting + CastRelease) A looping "channel energy" state while Casting, then the release clip on the trigger
Channel Healing Stream, Blizzard Bool HealingStream A looping state while the bool is true

Step by step: a warrior's Shield Bash (instant)#

  1. Clip: import the swing (Asset Store sword-and-shield pack, Mixamo "Shield Bash", or UAL1 Sword_Attack as a stand-in). Humanoid, Loop Time off, Root Transform baked. Name it Warrior_ShieldBash.
  2. Parameter: Animator > Parameters > + Trigger ShieldBash.
  3. State: on the Actions layer, create a state ShieldBash with the clip.
  4. In: Any State -> ShieldBash, Has Exit Time off, Duration 0.05, condition ShieldBash.
  5. Out: ShieldBash -> Actions idle/empty state, Has Exit Time on (exit at about 0.9), Duration 0.15.
  6. Data: Content Studio > Skills > Shield Bash > AnimationParameter = ShieldBash. Commit. Restart the World server.

Step by step: a mage's Fireball (cast bar, then release)#

  1. Clips: Mage_Cast_Loop (hands gathering energy, loop on) and Mage_Fireball_Release (throw, loop off).
  2. Parameters: the shared Casting bool already exists; add Trigger Fireball.
  3. States on the Actions layer: - CastLoop with Mage_Cast_Loop. Any State -> CastLoop when Casting true (no exit time). - FireballRelease with the release clip. Any State -> FireballRelease on trigger Fireball. - CastLoop -> idle when Casting false (covers cancels and interrupts). - FireballRelease -> idle on exit time.
  4. Data: Fireball's AnimationParameter = Fireball. Restart the World server.

Many spells can share CastLoop (it's driven by the shared Casting bool) and only differ in their release trigger.

Step by step: a channel (Healing Stream)#

  1. Clip Healer_Channel_Loop, loop on.
  2. Bool parameter HealingStream; state HealingStream with the clip.
  3. Any State -> HealingStream when true (Can Transition To Self off); back to idle when false.
  4. Data: AnimationParameter = HealingStream.

Casting while running: the upper-body mask#

To let a character swing or cast while its legs keep running: 1. Project > Create > Avatar Mask, name it UpperBody. In Humanoid, turn off the legs and the root (click them red); keep the body, arms and head. 2. Animator > Layers > Actions > gear icon > Mask = UpperBody, Blending Override, Weight 1.

If some skills should take over the whole body (a leap, a whirlwind), put them on a second, unmasked layer.

Giving each class its own look#

All classes share AxiomCharacter.controller; what makes them look different is their skills: - Class-only skills (Shield Bash for warriors, Fireball for mages) each have their own AnimationParameter. This is the main way, and it works today. - Shared skills (a basic attack every class has) are one row, so they look the same for everyone. To vary them, either give each class its own row of that skill (each with its own parameter), or add a WeaponType int parameter (0 unarmed, 1 one-hand, 2 two-hand, 3 staff, 4 bow) set from the equipped weapon and branch on it inside the Attack state. WeaponType is not wired yet: it needs a few lines in CharacterAnimator reading the equipped weapon. - Per-class idles and runs (a mage walks differently from a warrior): use an Animator Override Controller per class that swaps the locomotion clips, and pick it by class when the character spawns. Also not wired yet (a small addition to the spawn code).

A class sheet to fill in#

Plan each class in one table before importing anything:

Skill Kind Parameter Type Clip Layer
Shield Bash instant ShieldBash Trigger Warrior_ShieldBash Actions (upper body)
Whirlwind channel Whirlwind Bool Warrior_Whirlwind_Loop FullBody
Fireball cast + release Fireball Trigger Mage_Fireball_Release (+ shared CastLoop) Actions
Healing Stream channel HealingStream Bool Healer_Channel_Loop Actions
