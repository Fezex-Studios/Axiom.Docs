Cookbook (How-To)

Add an Ability#

Abilities are data: a Skills row, Effects rows that say what happens, optional SkillSteps for multi-stage skills, optional statuses. The client gets them in W2CSkillCatalog; the server runs every cast. Background: Combat (cast pipeline, effect kinds, statuses), Progression (classes, ranks, points), Skill plots (note).

The simple version (a cast + damage + a DoT, in SQL) is the Ignite recipe. Here we build a multi-step Mage spell, Arcane Volley: a bolt flies to the target, then jumps to 2 more enemies; if the first target is below 30 % health it also slows them.

1. The skill - Content Studio ▸ Combat ▸ Skills#

Column Value Notes
Name, Description Arcane Volley, "A bolt that leaps between enemies." tooltip text
ClassId 3 (Mage) 0 = no class (items, NPCs)
TargetRule 0 Enemy 0 Enemy, 1 Self, 2 Friendly, 3 Area Enemies, 4 Area Allies, 5 Doodad
Range, CastTimeMs, CooldownMs, ManaCost 30, 1200, 10000, 25
OnGlobalCooldown, IsSpell, RequiresFacing, CastWhileMoving 1, 1, 1, 0 spells use SpellPower and can be interrupted
RequiredLevel, MaxRank, RankLevelStep, RankBonusPct, PointCost 10, 3, 5, 10, 1 rank 2 at 15, rank 3 at 20; +10 %/rank
IconName Skills/Axiom/Mage/arcane_volley → Resources/Icons/Skills/Axiom/Mage/arcane_volley.png
AnimationParameter Cast an Animator trigger (or your own, e.g. ArcaneVolley)
IsStarter, NpcOnly, IsPassive 0, 0, 0

Leave MinDamage/MaxDamage at 0 - damage comes from effects.

2. The steps - Skill Steps (child rows of the skill)#

StepNo DelayMs TargetMode Projectile / chain Condition Animation / VFX
1 0 0 Target ProjectileSpeed 25 (m/s) – Cast, arcane_bolt
2 0 5 Chain ChainJumps 2, ChainRange 8, MaxTargets 3 – –, arcane_arc
3 0 0 Target – ConditionKind 3 TargetHealthBelowPct, ConditionParam 30, ElseStepNo 0 –

Other modes: 1 Self, 2 AreaAtTarget, 3 AreaAtCaster (Radius), 4 Cone (ConeDegrees), 6 Line. Repeat + RepeatIntervalMs + Channeled make channels (ticks stop if you move). Conditions: 1 TargetHasStatus, 2 CasterHasStatus, 3 TargetHealthBelowPct, 4 CasterHealthBelowPct, 5 DistanceBelow, 6 TargetIsPlayer, 7 Chance; ConditionNot inverts; ElseStepNo jumps (0 = skip).

3. The effects - per step (Effects, OwnerType 6 = skill step)#

Step Kind Target Min-Max School Coefficient RefId
1 6 Damage 1 target 22-30 4 Arcane 0.6
2 6 Damage 1 target 12-16 4 Arcane 0.3
3 2 Apply Status 1 target 1-1 the Slowed status

A skill with steps runs the steps instead of its own effects. The inspector shows them as sentences: "Deal 22-30 Arcane damage + 0.6× power".

The status (Combat ▸ Statuses): Arcane Slow, debuff, DurationMs 4000, a StatusModifiers row: Stat 24 (Move Speed Pct), Flat -30 (percentage stats add their points in Flat, like the shipped Hamstrung -40 and Chilled -35). Icon under Resources/Icons/Status/.

4. Client presentation#

  • Icon: the PNG at the IconName path. Missing → the slot shows text.
  • Animation: AnimationParameter on the skill (cast release) and on steps; a parameter the Animator doesn't have falls back to CastRelease (spells) or Attack (weapon skills). To add a dedicated clip: a trigger ArcaneVolley + a state in the Actions layer (animator controller).
  • VFX: VfxKey loads Resources/Vfx/<key> (Resources/Vfx/arcane_bolt.prefab). With ProjectileSpeed > 0 the client flies it from caster to target over the server's flight time; cosmetic flights are budgeted in crowds. No prefab = no visual, gameplay unaffected.

5. Learning it#

Players learn class skills from the spellbook with skill points once RequiredLevel is reached (C2WLearnAbility); ranks unlock every RankLevelStep levels. IsStarter = 1 gives rank 1 to new characters; HotbarSlot places it on the bar. Passive skills use AbilityPassiveModifiers. (Progression)

6. Giving it to an NPC#

NPCs ▸ NPC Abilities (or the NPC wizard): NpcTemplateId, SkillId, Priority (higher first), Target (0 Current Target, 1 Self, 2 Hurt Ally, 3 Random Enemy), MinHealthPct/MaxHealthPct (use below 50 % only…), Phase (boss phases), Chance, CooldownMs, InitialDelayMs. NPC-only skills set NpcOnly = 1 so they never appear in a class book.

7. Test#

  1. Content Studio F5, commit, restart the World server; the log loads skills and plots without warnings about your rows.
  2. Log in a level-10 Mage, learn it (K), drag it to the bar, cast on a group of monsters: the bolt flies, jumps to two more, the low-health target gets the slow icon.
  3. GM panel: Set Level / Clear Cooldowns to iterate quickly (needs World:AllowDebugCommands for levels).

When you need code#

  • A new effect kind (a verb that doesn't exist: "swap places with the target") → EffectKind + a case in EffectApplier.Check/Apply + the Content Studio enum (recipe).
  • A new stat → A new stat.
  • A new target mode or condition → SkillStepTarget / SkillStepCondition and the plot runner, plus ContentEnums.cs.
  • Anything that should show on the client beyond icon/animation/VFX (a ground marker while aiming) → client code.
