Tools

World Building Tools#

The world is 512 m tile scenes streamed around the player on the client (World streaming) and, on the server, the exported collision, heightmaps, navmesh and zone map built from those same scenes (World files). Placement of NPCs, doodads and spawn points lives in worldserver.db, edited from the scene with markers.

The order of work for a new area#

1  World Tiles     create aligned terrain tiles (or split an existing scene)       → tile_X_Z scenes
2  Unity           sculpt, paint, place scenery (static props, buildings, water)
3  World Tiles     Add all tile scenes to Build Settings; Validate world partition
4  World Tiles     Export All Terrain                                                → Data/terrain_data/*.achtmap
5  Server Exports  Movement Collision ▸ Export                                       → client StreamingAssets + server Data/world_collision
6  Zones           paint the zone, Save                                              → zones.aczmap (client + server)
7  World Map       place NPC spawners, Scene → DB
8  Doodads         place ore, herbs, chests, stations, Save
9  Spawn Points    respawn points, Scene → DB
10 NavMesh         Bake (only changed pages)                                         → Data/navmesh
11 HLOD Proxies    Bake                                                              → Resources/World/Proxies
12 Maps            Rebuild Terrain Atlas, Bake Loaded Scene Map, Export Scene Map Points
13 restart the World server; play

Steps 4, 5, 10 must be redone whenever the ground or solid scenery changes; the checklist says exactly which.

1. Tile scenes and terrain#

Dev Tools ▸ World Tiles:

  • Choose a rectangle of tiles (or Tile under Scene camera) and create terrain tiles: 512 m Unity terrains placed at real world coordinates that auto-connect at the seams, one scene per tile in Assets/AxiomMMOKit/Axiom.Client/World/Tiles/<area>/tile_X_Z.unity.
  • Preview split / Split active scene into tile scenes: move a big hand-built scene's static scenery into the tile it belongs to.
  • Work on several tiles at once by opening them additively with main_world.
  • Add all tile scenes to Build Settings (a tile missing there is treated as empty sea at runtime).
  • Validate world partition: oversized terrains, objects outside their tile, and similar.

Rules: author scenery at world coordinates inside its own tile; don't put gameplay objects (spawned things) in tiles - those come from the server. Static colliders on the movement collision layers are what players walk on.

2-5. Exports for the server#

  • Export All Terrain (World Tiles) or Tools ▸ Axiom ▸ World ▸ Terrain ▸ Export Heightmap For Server… per terrain: full-resolution .achtmap files used for NPC ground snapping and line of sight. Re-export as the last step of every sculpting pass.
  • Tools ▸ Axiom ▸ Server Exports ▸ Movement Collision ▸ Export: the triangles players collide with (Server exports). Incremental and byte-identical to a full rebuild; client and server must have identical files.

6. Zones#

Dev Tools ▸ Zones: add a zone (Key lowercase and permanent, display name, subtitle, level range, PvP mode, colour), paint it with the round brush on the top-down map (optional background image) or directly on the terrain in the Scene view (32 m cells), Save - writes StreamingAssets/World/zones.aczmap and the server's copy. Open zone opens every tile scene it touches; Organize moves tile scenes into folders per zone (cosmetic). Server use of zones: Zones & terrain.

7-9. NPCs, doodads, spawn points#

Tab Table Marker
World Map NpcSpawners (TemplateId, X/Y/Z, Count, Radius, DungeonId) NpcSpawnerMarker
Doodads DoodadSpawns (TemplateId, position, yaw, scale, respawn, DungeonId) DoodadSpawnMarker (with a model preview)
Spawn Points SpawnPointTables (name, position, IsDefault) PlayerSpawnPointMarker

Common workflow: Load → DB → Scene (markers appear, each with its DbId) → move/add/delete markers → Scene → DB (one transaction with a real diff) or Export Patch. Doodads: Place mode drops one per click on the ground. If the World server is running, saving writes a patch only; restart the server.

Markers are editor-only objects; they're saved in whatever scene they're in but never reach players. Keep them in main_world or the tile they're on.

Then Dev Tools ▸ Validate ▸ Run Checks (missing templates, nothing under a spawner, stacked duplicates, default spawn point).

10. Navmesh#

Dev Tools ▸ NavMesh ▸ Bake (runs Axiom.Tools.NavBake on the exported collision; only changed pages). The overlay (also Tools ▸ Axiom ▸ World ▸ Navigation ▸ Show NavMesh Overlay) tints walkable areas and draws the edges where NPCs stop. A hole where you expected floor is almost always a collider missing from the movement export. Details: NPC navigation.

11. HLOD#

Dev Tools ▸ HLOD Proxies ▸ Bake: a low-poly terrain + baked top-down texture + merged big props per tile, into Resources/World/Proxies and the TileProxies manifest. Only changed tiles rebake.

12. The in-game map#

Menu
Tools ▸ Axiom ▸ World ▸ Maps ▸ Rebuild Terrain Atlas… rebuilds the map pages from the exported heightmaps and the zone map, without opening scenes
Bake Loaded Scene Map loads a page's tile scenes, captures a north-up picture of the scenery, saves it as that page in Resources/UI/Maps
Export Scene Map Points writes every MapPointAnchor in the open scenes (services, landmarks) to Resources/UI/Maps/points.json

Put a MapPointAnchor on a vendor, banker, portal or landmark to give it a map pin. Tools ▸ Axiom ▸ Validation ▸ Maps ▸ Atlas and Coordinates checks the result.

Housing areas#

Tools ▸ Axiom ▸ World ▸ Housing ▸ Create Zone Outline: draw the corners of a plot area in the scene and set the HousingAreas id it belongs to; Export Loaded Zone Outlines validates and writes housing/zones.json - copy it to the World server's Data/housing and restart. Setup items install the starter house prefabs, placard and preview material; Furniture ▸ Build and Install Starter Furniture builds the starter chair/piano/fireplace prefabs.

Dungeons#

A dungeon is tile scenes in a far-away block of the grid (e.g. tile_32_32 = 16 384 m) built like any other area, plus rows created by the Dungeon wizard (Create wizards). Its spawners carry DungeonId. Export collision, terrain and navmesh for its tiles like anywhere else.
