Getting Started

Learning Path#

Axiom is large. Don't read everything; follow the track that matches what you'll build, and do the exercises - each one touches the real code.

Day 1 - everyone#

  1. Quick start: get the four servers running and log in.
  2. Architecture overview: the five programs and who owns what.
  3. Login & world entry: follow one player from password to standing in the world.
  4. The editor suite: open Tools ▸ Axiom ▸ Home and click through every tool once.

Exercise: create two characters, play with two clients (ParrelSync), open the GM panel (F12) and teleport one to the other.

Track A - gameplay programmer#

Step Read Exercise
1 The World server - start-up, tick, threading, Scheduler Find where PatronService is constructed, registered and started.
2 Networking, Client networking Do Add a packet (Inspect) end to end.
3 Players & sessions, Persistence flow Do Add a persisted field. Kill the server mid-session; see what survived.
4 Combat, NPCs & AI Add a skill with a new effect kind.
5 Interest & replication, Movement Run a load test preset; read the tick stage report.
6 Add a server system, Add a table Build playtime rewards with a table and a Lua event.

Track B - client / UI programmer#

Step Read Exercise
1 Client overview, Client networking Put a breakpoint in a handler; watch WorldLoader.RunWhenReady delay it during entry.
2 Client data & state Find every place LocalCharacterState.Reset is called and why.
3 User interface Do Add a UI window.
4 Characters, gear & animation Add a gear variant (_Female) and see the Wardrobe pick it.
5 World streaming, Input & camera Lower the floating-origin threshold and walk across a shift; fix anything that jumps.

Track C - designer / world builder#

Step Read Exercise
1 worldserver.db, Content Studio Change an item's stats, commit, restart, see it in game.
2 Create wizards Make an NPC, a loot table and an item with the wizards.
3 Add content: a hamlet Build it.
4 World building tools, Add a zone Paint a new zone and give it a respawn point.
5 Doodads, Add a doodad Make the locked gate.
6 Quests, Lua scripts A three-quest chain with a Lua reward.

Track D - running a shard#

Configuration → MySQL → Server scripts → Deploy → Load testing → Troubleshooting.

Habits that save time#

  • Read the World log's first screen after every start; catalogues tell you which rows they skipped.
  • After changing Axiom.Network or Axiom.Movement: rebuild, copy both DLLs, Validate Netcode Build.
  • After changing the world in Unity: the export checklist.
  • Content goes through Content Studio (patches in git), never hand edits to a live worldserver.db.
  • When unsure where something lives, search this site (/) or the reference pages.
