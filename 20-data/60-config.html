Configuration#

Every server uses standard .NET configuration: JSON files plus environment variables. The full list of options with defaults and descriptions is generated in the configuration reference. This page explains the files and the settings that matter.

Load order#

Later sources override earlier ones:

Server Order
World appsettings.json → World.Performance.json → appsettings.Local.json → environment variables
Auth appsettings.json → appsettings.{Environment}.json → appsettings.Local.json → environment variables
Persistence appsettings.json → appsettings.{Environment}.json → appsettings.Local.json → environment variables
Auction appsettings.json → appsettings.{Environment}.json → appsettings.Local.json → environment variables
  • appsettings.json is committed: defaults and non-secret settings.
  • appsettings.Local.json is git-ignored: your passwords, secrets, machine paths. Copy appsettings.Local.example.json to create it.
  • Environment variables win over everything, with __ for nesting: World__InternalSecret=…, ConnectionStrings__Persistence=…, Auth__LaunchTokenSeconds=60. Use these on servers and in containers.

Values that must match#

Value World Auth Persistence Auction Client
Internal secret (32+ random chars) World:InternalSecret Auth:InternalSecret InternalSecret Persistence:InternalSecret —
Auth URL World:AuthServerUrl Kestrel:Endpoints:Http:Url — — AuthBaseUrl in WorldDirectory.json / -auth-url (AuthServerAddress)
Persistence URL World:PersistenceBaseUrl WorldDirectory:PersistenceBaseUrl Kestrel…Url Persistence:BaseUrl —
Auction URL World:AuctionServerUrl — — Kestrel…Url —
World id WorldDirectory:Id an entry in WorldDirectory:Worlds[].Id — — —
Game data key World:ClientContent:KeyHex — — — GameDataCrypto.Key
Protocol ProtocolVersion in Axiom.Network.dll the client's copy of the DLL

Every server refuses to start if its secret is missing, still a placeholder, or shorter than 32 characters. Generate one:

[Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Max 256 }) -as [byte[]])

openssl rand -base64 48

and a 64-hex game data key:

openssl rand -hex 32

Performance: logout waves and the persistence queue#

Setting Default Notes
DisconnectsPerTick 32 Disconnect clean-ups (save, despawn, leave packets to everyone who saw the player) a zone host runs per tick. A mass logout is spread over several ticks.
DisconnectMilliseconds 4 Soft time limit for those clean-ups per tick (0.5–40); at least one always runs.
MaxServiceRequests 64 Persistence HTTP calls in flight at once. The HTTP client only opens 20 connections, so raising this alone does not add throughput.
QueuedServiceRequests 4096 Persistence calls allowed to wait for a slot. When full, a call fails with ServiceBusyException; character saves retry with the same SaveSeq (no data loss) but flood the log. At 512 a 1,000-player logout overflowed it; 4096 holds roughly 4,000 waiting saves.

Raise QueuedServiceRequests further for bigger shards rather than MaxServiceRequests. A deep queue means the last save of a wave waits a few seconds; the 10 s request timeout covers the wait.

World.Validate() runs before anything opens a socket and refuses a broken config.

Network (NetworkConfig)#

Port (7777): the UDP port LiteNetLib listens on. Open it in the firewall for players.

Database (DatabaseConfig)#

WorldDb (Data/worldserver.db) and PatchDirectory (SQL/patches/, empty = next to the exe). The Host/Port/Name/User/Password fields are unused leftovers (the World server doesn't use MySQL).

WorldDirectory (WorldDirectoryReporterConfig)#

Enabled, Id (must exist in Auth's list), PublicHost/PublicPort (what clients connect to: your public IP or DNS name, never 0.0.0.0), IntervalSeconds (5).

nlog.config#

Console + rolling file. Axiom.* loggers at Info; set minlevel="Debug" for a system while debugging.

Auth server#

src/Servers/Axiom.Server.Auth/appsettings.json. (Auth.WorldDirectory.json and the World's World.WorldDirectory.json hold the same WorldDirectory section as a template, but Program.cs doesn't load them; the copy in appsettings.json is the one used.)

Setting Default Notes
ConnectionStrings:Auth MySQL axiom_auth. Local.
Kestrel:Endpoints:Http:Url http://0.0.0.0:3000 Behind Caddy: http://127.0.0.1:3000. A Kestrel:Endpoints:Https entry with a Certificate serves HTTPS directly (HTTPS).
Auth:InternalSecret Local.
Auth:GameDataPath gamedata.bin File served by /gamedata/db.
Auth:MaxLoginAttempts, LockoutMinutes, AccountLockAttempts 5, 15, 50
Auth:LaunchTokenSeconds, RefreshTokenDays 120, 30
Auth:TrustForwardedFor false Only behind a reverse proxy. Its headers are believed only from this machine or TrustedProxies.
Auth:TrustedProxies [] Proxies on other machines (addresses or networks). Loopback is always trusted.
Auth:RequireHttps true Refuse plain HTTP from other machines. This machine is always allowed.
Auth:PlainHttpAllowedNetworks [] Allowed plain HTTP anyway; "private" = the usual LAN ranges. LAN testing only.
WorldDirectory:Worlds[] Id, Name, Host, Port, Restrictions, Maintenance, MaxCharacters, optional PersistenceBaseUrl
WorldDirectory:StaleAfterSeconds 25 A world with no heartbeat for this long shows offline.

Rate limiting policies (auth-strict on login/register, world-list on /worlds) are set up in Program.cs.

Persistence server#

Setting Notes
ConnectionStrings:Persistence MySQL axiom_persistence. Local.
AutoMigrate top-level, default true: create the database and tables, and apply new migrations, on start. false: manage the schema by hand (dotnet ef database update); start-up then only reports what's missing.
InternalSecret top-level key. Local.
Kestrel:Endpoints:Http:Url http://0.0.0.0:7778. Bind to localhost or a private network; only World servers (and Auction) should reach it.

A complete local setup#

src/Servers/Axiom.Server.World/appsettings.Local.json:

{
  "World": {
    "InternalSecret": "PASTE-THE-SAME-48-CHAR-SECRET-HERE",
    "ItemUidNode": 1,
    "ClientContent": {
      "KeyHex": "PASTE-64-HEX-CHARS-MATCHING-GameDataCrypto.Key",
      "OutputPaths": [
        "F:/Development/AxiomCore/Axiom.Client/Assets/StreamingAssets/GameData/gamedata.bin",
        "F:/Development/AxiomCore/AxiomCore/src/Servers/Axiom.Server.Auth/bin/Debug/net10.0/gamedata.bin"
      ]
    }
  }
}

src/Servers/Axiom.Server.Auth/appsettings.Local.json:

{
  "ConnectionStrings": { "Auth": "Server=127.0.0.1;Port=3306;Database=axiom_auth;User=axiom;Password=…;" },
  "Auth": { "InternalSecret": "PASTE-THE-SAME-48-CHAR-SECRET-HERE",
            "GameDataPath": "F:/Development/AxiomCore/Axiom.Client/Assets/StreamingAssets/GameData/gamedata.bin" }
}

Axiom.Server.Persistence/appsettings.Local.json:

{
  "ConnectionStrings": { "Persistence": "Server=127.0.0.1;Port=3306;Database=axiom_persistence;User=axiom;Password=…;" },
  "InternalSecret": "PASTE-THE-SAME-48-CHAR-SECRET-HERE"
}

Axiom.Server.Auction/appsettings.Local.json:

{
  "ConnectionStrings": { "AuctionDb": "server=127.0.0.1;port=3306;database=axiom_auction;user=axiom;password=…;" },
  "Persistence": { "InternalSecret": "PASTE-THE-SAME-48-CHAR-SECRET-HERE" }
}
