12. Adding Armor#

Helmets, chest pieces, legs, gloves and boots, including separate male, female and per-race versions of the same piece.

Time: 15 minutes for a hat; longer for skinned armour, depending on the modelling. You'll use: Create > Item, Gear Workshop, Characters & Races.

Part A: Socket or Skinned?#

Every piece of armour attaches one of two ways. Choosing right is the most important decision in this guide.

Socket (rigid) Skinned (bends)
Works like a magnet stuck to one bone clothing worn over the skeleton
Moves with one bone, never changes shape with every bone; bends at elbows, knees, waist
Use for helmets, hats, crowns, masks, shoulder pads, shields, backpacks chest, robes, shirts, legs, gloves, boots, hoods, capes that wrap
Model needs any mesh (a Mesh Renderer) a mesh bound to the same skeleton as the body (a Skinned Mesh Renderer)
Adjust with position / rotation / scale offsets nothing to adjust: it follows the bones
Per-body versions usually one fits all usually one per body shape (male, female, per race)

The rule: if it would look broken when the character bends a joint, it must be Skinned. Otherwise use Socket.

Part B: Item and stats (both kinds)#

  1. Make the icon (guide 10, step 1).
  2. Tools > Axiom > Create > Item…, Copy an existing one: a piece for the same slot.
  3. Details: name, description, icon, category armour, rarity, level.
  4. Gear stats:
Field Example Notes
EquipSlot 2 1 Head, 2 Chest, 3 Legs, 4 Hands, 5 Feet
ArmorKind 2 (Leather) 1 Cloth, 2 Leather, 3 Plate
ArmorRating 40 damage reduction
Strength … Spirit stat bonuses
AllowedClasses 0 0 = whoever the armour kind allows
Class May wear
Warrior cloth, leather, plate
Healer cloth, leather
Mage cloth
  1. Check, Create. Note the item id.

Part C: A Socket piece (helmet, hat, cap)#

  1. Prepare the prefab. Its origin should be where it meets the head. Models cut from a full character (for example Male_Ranger_Head_Hood from an outfit pack) are often modelled at head height, so their origin is at the feet: put the mesh as a child of an empty root and move the child down until it sits on the origin. Delete any Armature that came with it.
  2. Tools > Axiom > Characters & Gear > Gear Workshop. Pick any race and gender.
  3. Item id: yours. Equip slot: Head. Gear prefab: your prefab.
  4. Attach: Socket. In use (drawn): Head.
  5. Hide body parts: Hair for a cap or hood (so hair doesn't poke through); Head only for a full helm that covers the face.
  6. Preview in Scene. Nudge it with the gizmo, then Read gizmo edits. Typical fixes: Rotation X ±90 if it lies on its side; Scale 0.01 or 100 if the units are off.
  7. Save for: Everyone → Save to world database.
  8. Check it on the other bodies: switch race and gender at the top and press Rebuild preview. If the female head needs it placed differently, see Part E.

Part D: A Skinned piece (chest, legs, gloves, boots)#

Skinned armour must be made on the body's own skeleton. This happens in your 3D program (Blender shown):

  1. Open the body's source file, the same rig you use in Unity (for the female version, the female body).
  2. Model the armour around the body in its rest pose, slightly outside the skin.
  3. Bind it to the skeleton: select the armour, then shift-select the armature, Ctrl+P > With Automatic Weights. Better: a Data Transfer modifier on the armour, source = the body mesh, Vertex Data > Vertex Groups, so it bends exactly like the skin under it.
  4. Test: pose the arms and legs. Fix tearing in Weight Paint mode.
  5. Export FBX: the armour mesh and the armature, same scale and axis settings as the body. Never rename bones.
  6. In Unity: select the FBX; Rig tab = the same Animation Type as the body (Humanoid or Generic). Expand it: the mesh must show a Skinned Mesh Renderer.
  7. Make a prefab of it, root at position 0, 0, 0.

Then in the Gear Workshop:

  1. Pick the race and gender whose rig you modelled on.
  2. Item id, Equip slot (Chest, Legs, Hands, Feet), Gear prefab.
  3. Attach: Skinned. (Offsets disappear: they don't apply.)
  4. Hide body parts: what it covers, e.g. Torso + Arms for a chest piece, Legs for pants, Feet for boots, Hands for gloves.
  5. Preview in Scene. "Armour bound to the body's bones" = good. An error names the bone that's missing: the armour wasn't made on this skeleton.
  6. Save for: Everyone → Save to world database. This is the base version every body wears unless it has its own.

Outfit packs (e.g. Quaternius Modular Character Outfits) are already skinned to their pack's body. Import the whole pack with Axiom > Characters & Gear > Import Outfit Pack…, then fit each part as above. Their pieces replace the body under them and come in sets (a tunic plus its sleeves, pants plus boots): hide every part a piece covers, and where one piece needs another to close a gap, build the item from a copy of the pack's whole-outfit prefab with the other pieces switched off. The worked example, with the exact parts to hide, is guide 16, "Sets, not single pieces".

In the Gear Workshop, Load reads the item's look as it's saved, so press it before changing the fields, not after.

Part E: Female, male and per-race versions#

A variant is a second prefab for the same item. No database change: the item keeps one gear visual row (slot, sockets, hidden parts, offsets), and each body picks the most specific prefab that exists.

A character with body… tries, in order
Character_Elf_Female {Prefab}_Elf_Female → {Prefab}_Female → {Prefab}
Character_Elf {Prefab}_Elf → {Prefab}
Character_Default_Female {Prefab}_Female → {Prefab}
Character_Default (or a faction body) {Prefab}

To make the female version of the chest piece from Part D:

  1. Model it on the female body (Part D steps 1–7).
  2. Gear Workshop: Body = a race with Female. Item id = the same item. Press Load: it reads the item's saved row.
  3. Drag the female prefab into Gear prefab. Preview in Scene to check it binds.
  4. Save for: pick Variant: Female (or Variant: Elf_Female for that race only) → Save as 'Female' variant.

The workshop copies the prefab next to the base in Resources with the right name. Nothing to export: variants are client assets.

See it all at once: Dev Tools > Characters & Races > Wardrobe lists every gear piece against every body you have, and what each body wears. ⚠ base mesh on a skinned piece means that body wears armour made for another rig: make it a variant.

Part F: Send it to clients#

  1. Dev Tools > Overview > Export game data now (needed after Save to world database; not after a variant).
  2. Restart the World server.
  3. Press Play and equip it, on a male and a female character.

Checklist#

  • [ ] Item with gear stats: slot, armour kind, rating
  • [ ] Right attach type (Part A)
  • [ ] Hidden body parts set
  • [ ] Saved for everyone; variants saved for the bodies that need them
  • [ ] Wardrobe shows ✓ (not ⚠) for every body
  • [ ] Game data exported, World server restarted, patches committed

If it doesn't work#

Problem Fix
"Skinned attachment requires a Skinned Mesh Renderer" the mesh wasn't bound to the armature before export (Part D step 3), or it's really a Socket piece
A bone name in the error the armour was made on a different skeleton, or a bone was renamed
Stretched, exploded or floating different skeleton or rest pose, or export scale differs from the body's
Skin pokes through set Hide body parts, or push the armour out a little in Blender
Skin wedges on a man's chest, fine on a woman the male body's separate Shoulders part
Armour lit oddly, dark from some sides an Unreal-style normal map
Hat floats far above the head the mesh origin is at the feet (Part C step 1)
Women wear the men's version no _Female variant, or no female body: check Characters & Races
"Invalid gear visual: item X, slot Y" the Prefab Key is empty: assign the prefab
Equipped but invisible game data not exported; or the class can't wear that armour kind
