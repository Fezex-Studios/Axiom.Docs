Axiom Server Lua SDK#

Server-side scripting for the Axiom World server: react to what players do, give rewards, run timed events, add chat commands, spawn NPCs and keep small saved values. Scripts run inside the server's MoonSharp Lua (Lua 5.2), sandboxed and time-limited.

Contents#

Path What
README.md This guide and the full API reference
library/axiom_server.lua Editor definitions: autocomplete and type checking (not loaded by the server)
examples/ Complete, working scripts to copy from
TEMPLATE.lua A starting point for a new script
.luarc.json Editor setup for working inside this folder

Where scripts go#

Every .lua file in Axiom.Server.World/Lua/Server/ (and its subfolders) loads when the World server starts. To try an example, copy it there and restart the server. The server log shows [LuaEngine] Loaded script: ... for each file, and any error with its file and line.

A script runs once at startup: that's where it registers its hooks, commands and timers. After that, only those functions run, when their event happens.

Editor setup (autocomplete)#

  1. Install VS Code and the Lua extension (by sumneko / LuaLS).
  2. Open the folder Axiom.Server.World/Lua/Server/. Its .luarc.json points the extension at LuaSDK/Server/library, so Server:, player: and npc: autocomplete with every function and its parameters, and Server:On(" lists every event with the right handler arguments.

The basics#

-- React to an event (by name; the handler gets the arguments in the table below).
Server:On("OnKill", function(player, npcTemplateId)
  player:SendMessage("You killed a " .. Server:NpcName(npcTemplateId))
end)

-- A chat command: ".hello" runs this and nobody else sees the message.
Server:RegisterCommand("hello", function(player, args)
  player:SendMessage("Hello, " .. player:GetName())
end)

-- Something on a timer (milliseconds).
Server:Every(10 * 60 * 1000, function() Server:Broadcast("Remember to drink water!") end)

-- Save a value that survives a restart (per character, or shared).
player:SetData("quests.done", 3)
Server:SetData("event.highscore", 1200)

Rules of the sandbox#

  • Lua 5.2 (MoonSharp). No // integer division (use math.floor(a / b)), no goto.
  • Soft sandbox: string, table, math, os.time/os.clock and coroutine are there; no io, no os.execute, no require of arbitrary files, no network.
  • Time limit: each hook, command or timer call may run 200,000 Lua instructions (loading a script: 5,000,000). Past that it's stopped and logged. A hook or repeating timer that's stopped 3 times is switched off until the server restarts. Plenty for normal logic; it only bites runaway loops.
  • Errors never crash the server: they're logged with the file and line, and that call stops.
  • Everything runs on the server's tick thread, in order. No locking needed; don't do slow work.
  • Kept objects: a Player or Npc you keep in a variable stays safe after they leave or die: player:IsOnline() / npc:Exists() become false and the getters return 0 / "".
  • Money is in copper: 10000 = 1g, 100 = 1s.
  • Saved data (GetData/SetData) takes strings, numbers and booleans only (no tables), keys up to 200 characters, text up to 4000; it's written to Data/lua_data.json within 5 seconds.

Events#

Hook with Server:On("Name", fn) or Server:RegisterPlayerEvent(Events.Name, fn).

Event Id Handler arguments When
OnConnect 1 player Entered the world.
OnDisconnect 2 player Leaving. The player's getters still work during the hook.
OnLevelUp 3 player, newLevel Gained a level.
OnChat 4 player, channel, message Sent a chat message. Return false to stop it being sent.
OnDeath 5 player, killerNpcTemplateId The player died (0 = not killed by an NPC).
OnInteract 6 player, targetTemplateId, targetKind Used an NPC or doodad.
OnItemUse 7 player, itemTemplateId, slot Used an item (after it succeeded).
OnHarvest 8 player, doodadTemplateId, itemTemplateId, quantity Got an item from a doodad action (harvest, chest, crop). Once per item.
OnKill 9 player, npcTemplateId An NPC the player attacked died.
OnEnterZone 10 player, zoneId, zoneKey, previousZoneId Crossed into a zone (0 = no zone). Also on spawn.
OnDoodadUse 11 player, doodadTemplateId, funcId, actionType Any doodad action succeeded.
OnCraft 12 player, recipeId, itemTemplateId, quantity Finished a craft.
OnTheft 13 player, doodadTemplateId, ownerCharacterId Took someone else's crop, trade pack or cargo.
OnTradePackSold 14 player, packItemId, outletId, gold Delivered a trade pack.
OnTrade 15 player, partnerName, itemsGiven, itemsReceived, goldGiven, goldReceived A player trade went through.
OnPvpKill 16 player, victimName, victimFactionId, wasCrime Killed another player.
OnCrime 17 player, points, charge Committed a crime.
OnSentenced 18 player, guilty, jailSeconds, outlawed A trial's verdict.
OnTerritoryCaptured 19 player, territoryId Claimed a territory's seal in a siege.
OnWorldEvent 21 player, eventId, won Took part in a world event that ended.
OnTreasure 22 player, mapItemId Dug up a treasure.
OnClimb 23 player, doodadTemplateId Climbed something.
OnItemObtained 24 player, itemTemplateId, quantity An item went into the bag.
OnJuryVote 25 player, trialId Served on a jury.
OnAchievement 26 player, achievementId Completed an achievement.
OnSkillUse 27 player, skillId, targetNpcTemplateId An ability went off (0 = no NPC target).

OnChat: return false from the handler to stop the message being sent (filters). A message starting with . that matches a registered command never reaches OnChat.

Server:GetPlayer(networkId) Player or nil Online player by network id
Server:Broadcast(text) Chat line to everyone (System channel)
Server:Announce(text) Centre-screen announcement to everyone
Server:SpawnNpc(templateId, x, y, z) Npc or nil Spawn an NPC (y 0 = ground); never respawns
Server:GetNpc(networkId) Npc or nil
Server:NpcsNear(x, z, radius) Npc[] Nearest first, at most 100
Server:ItemName(itemId) / Server:NpcName(templateId) string
Server:GetData(key) / Server:SetData(key, value) value / bool Shared saved data
Server:Log/Warn/Error(text) To the server log
Server:GetTime() / Server:GetDateTime() / Server:Now() string / string / ms

Examples (examples/)#

File Shows

kill_rewards.lua Kill counter, milestone gold, a rare-drop chance

Tips#

  • Don't rely on player.NetworkId across logins - store player:GetCharacterId().
  • Prefix your saved-data keys with your script's name ("welcome.gifted") so scripts don't clash.
  • Give before you take, and check the result: GiveItem / TakeGold return false when they can't, so a reward script never takes payment for something it couldn't deliver.
  • Item and NPC ids are the ids in Content Studio (Items, NPC Templates).

For engine developers: adding to the SDK#

Bindings live in Core/Lua/Bindings/ (LuaServerBinding = Server, LuaPlayer, LuaNpc), with Core/Lua/LuaWorld.cs giving them the server's services. A public method on those classes is callable from Lua at once. Add new events to Core/Lua/PlayerEvent.cs (never reuse an id) and fire them with LuaEngine.FireEvent. Then update library/axiom_server.lua and this README.
