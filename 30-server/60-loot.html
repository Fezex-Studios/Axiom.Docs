Server Systems

Loot#

Piece File Job
LootRoller Core/Loot/LootRoller.cs Rolls a loot table: gold, independent entries, groups, grades. Pure, testable.
LootManager Core/Loot/LootManager.cs Corpses: creates them on NPC death, puts them in the interest grid, Loot All / loot window, expiry.
LootManager.Rolls Core/Loot/LootManager.Rolls.cs Party Need / Greed / Pass for good gear.
PartyManager.LootersFor Core/Social/PartyManager.cs Who may loot a party kill (loot rule).

Tables#

Table Meaning
LootTables Id, Name, MinGold, MaxGold (copper)
LootTableEntries ItemId, MinQuantity–MaxQuantity, GradeId (fixed grade, 0 = base), and either independent (GroupNo = 0: rolls its own Chance, 0.25 = one kill in four) or grouped (GroupNo > 0: picked by Weight when its group fires; AlwaysDrop entries always come with the group)
LootGroups per table and group number: the group's Chance (rolled once) and GradeDistributionId
ItemGradeDistributions 12 weights, one per grade: what grade gear from a group rolls ("Field drops" 600/300/90/10 for Crude/Basic/Grand/Rare)
NpcLootTables extra tables for an NPC on top of NpcTemplates.LootTableId (e.g. a shared rare table for every boss)

How a kill rolls: gold in MinGold..MaxGold; every independent entry rolls its chance; every group rolls its chance once and, if it fires, drops its always-drop entries plus one weighted pick, with a grade from its distribution. Content Studio's loot preview shows odds per entry, expected items per kill and a 1 000-kill simulator.

Corpses#

CombatManager.KillNpc → LootManager.CreateCorpse(npc, looters, shareIds):

  • Loot is rolled once, at death. What's in a corpse never changes, however often it's opened.
  • No items and no gold → no corpse.
  • A corpse is an IWorldEntitySource in the interest grid: it spawns on clients that come near (W2CSpawnCorpse) and despawns when looted empty or after 2 minutes.
  • Only the eligible looters may loot; everyone sees it.
  • Two interactions (F/G by default, from InteractableActions): Loot All (everything that fits goes through TryAddItem, gold added, the rest stays) and Open Loot (W2CLootWindow; each click is C2WLootTake for one entry or the gold). While a window is open every change re-sends it.

Party loot#

The party leader picks a LootRule (Axiom.Network/Shared/Social/SocialTypes.cs):

Rule Who may loot
FreeForAll anyone in the party near the kill
RoundRobin each kill goes to the next member in turn (of those near)
MasterLooter the master looter (leader by default) hands it out

In a shared free-for-all kill, gear of grade LootRollGrade (4 = Rare) or better doesn't go on the corpse: every looter gets a roll window (W2CLootRollStart, answered with C2WLootRollChoice, settled by W2CLootRollResult). Need beats Greed, then the highest d100 (ties re-rolled); no answer in LootRollSeconds (30) = Pass. The winner gets that exact copy in their bag, or by mail if it's full. Both numbers are CombatRules keys.

INSERT OR REPLACE INTO LootTables (Id, Name, MinGold, MaxGold) VALUES (40, 'Grey Wolf', 20, 60);

-- independent drops
INSERT OR REPLACE INTO LootTableEntries (Id, LootTableId, ItemId, Chance, MinQuantity, MaxQuantity, AlwaysDrop, GradeId, GroupNo, Weight)
VALUES (400, 40, 7,   0.70, 1, 3, 0, 0, 0, 0),     -- Wolf Pelt, 70 %
       (401, 40, 4,   0.15, 1, 1, 0, 0, 0, 0);     -- Healing Potion, 15 %

-- group 1: 5 % of kills drop ONE of these three rings, graded by the "Field drops" distribution
INSERT OR REPLACE INTO LootGroups (Id, LootTableId, GroupNo, Chance, GradeDistributionId) VALUES (40, 40, 1, 0.05, 1);
INSERT OR REPLACE INTO LootTableEntries (Id, LootTableId, ItemId, Chance, MinQuantity, MaxQuantity, AlwaysDrop, GradeId, GroupNo, Weight)
VALUES (402, 40, 6301, 0, 1, 1, 0, 0, 1, 50),
       (403, 40, 6302, 0, 1, 1, 0, 0, 1, 35),
       (404, 40, 6303, 0, 1, 1, 0, 0, 1, 15);

Changing how loot works (code)#

  • Personal loot (each player gets their own corpse contents): roll per looter in CreateCorpse and store contents per character on the corpse; filter the loot window and Loot All by looter.
  • Bind on pickup for raid drops: already supported per item (bind_type = 1).
  • Hook CombatManager.NpcDied (an event) to add bonus drops from a system without touching LootManager, e.g. a world event that drops tokens from every kill in its zone:
public void Initialize(ServiceContainer services)
{
    _players = services.Get<PlayerManager>();
    services.Get<CombatManager>().NpcDied += OnNpcDied;     // tick thread
}

private void OnNpcDied(NpcEntity npc, IReadOnlyCollection<int> fighters)
{
    if (!_eventActive || !_zone.Contains(npc.Position)) return;
    foreach (int id in fighters)
        if (_players.TryGetPeer(id, out var peer))
            _players.TryAddItem(peer, EventTokenItemId, 1);
}

WorldEventService does exactly this kind of thing.
