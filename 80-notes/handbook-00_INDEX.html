Content Handbook

Axiom Developer Handbook#

Start here. This handbook is the step-by-step manual for building content in Axiom: items, weapons, armour, animations, races, NPCs, and everything around them. Every guide is written as numbered steps you can follow with the editor open.

Open any guide from Tools > Axiom > Help, from the ? button on every Dev Tools tab, or from Tools > Axiom > Home > Guides.

The five things to remember#

  1. The World server owns the game. Items, NPCs, loot, skills and quests live in its SQLite database, worldserver.db. The Unity client only draws what the server tells it.
  2. Every tool writes twice: into worldserver.db (so it works on your machine now) and into a numbered SQL patch in src/Axiom.Server.World/SQL/patches (so it works on everyone else's). Commit the patch to git.
  3. Restart the World server after a content change. It reads content once, at startup.
  4. Items and gear visuals also need new game data for the client (gamedata.bin). Press Export game data now on the Dev Tools Overview, or restart the World server, which writes it on boot.
  5. When a packet changes, the protocol number changes. Rebuild Axiom.Network.dll and copy it into Assets/AxiomMMOKit/Plugins. The Dev Tools Overview tells you when the DLL and the source disagree.

Words used in these guides#

Word Means
World DB worldserver.db, the World server's content database (SQLite)
Persistence DB MySQL database axiom_persistence: characters, inventories, saves
Patch a numbered .sql file the World server applies on start if its database hasn't had it
Game data / gamedata.bin the encrypted file the client reads item names, icons and gear visuals from
Model key a name like Character_Elf_Female or NPC_ORC that the client looks up in the WorldObjectPrefabs catalog to find a prefab
Gear visual a row saying which prefab an item shows on the character, and how it attaches
Socket / Skinned the two ways gear attaches: glued to a bone, or bent with the skeleton (see guide 12)
Variant a second prefab for the same gear, for one gender or race: IronPlate_Female
