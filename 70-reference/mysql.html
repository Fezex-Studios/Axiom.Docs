mail_receipts#

from EF model (MailReceipt)

A note that a delivery key has already been posted. Other services (the auction house) send mail through an outbox that retries until it's told "yes". If their last attempt actually landed but the reply was lost - or they crashed before forgetting it - the retry carries the same key, and this table is how we recognise it and say "already done" instead of delivering twice. It has to be its own table rather than a column on Mail, because a player may have claimed (and so deleted) the mail before a late retry arrives. Receipts are tiny and only matter for as long as a retry can still be in flight; anything older than a few days can be deleted.

Column Type Required Default Notes
delivery_key varchar(64) PK
created_at_ticks bigint yes
