2. Tools Reference#

Every tool under the Axiom menu, what it's for, and where its data goes. The menu is grouped into sections; each section is a band of the menu separated by a line.

The four workspaces (top of the menu)#

Tool Shortcut Use it for
Home Ctrl+Alt+H The front door: setup status with a fix button next to every problem, the Create wizards, every tool with a description (searchable, with favourites), settings, guides
Content Studio Ctrl+Alt+E Editing any table in the world database: items, skills, NPCs, quests, shops. Ctrl+K go to, Ctrl+S commit, Ctrl+Z undo
Dev Tools Shift+Alt+D The day-to-day workbench: status dashboard, game data, characters and gear, world building (details below)
Server Control Start, stop and restart Persistence, Auth, World and Auction, with their logs inside Unity

Not sure where something is? Tools > Axiom > Help > Find a Tool… (or Home > Tools) and type what you want to do. Every button and field in every tool also has a tooltip: hover it.

Create ▸#

Wizards that build a complete piece of content in one window and save it as one patch. Use them for anything new; use Content Studio to change what exists. Every wizard: pick something to copy (recommended) or start blank, fill in the details, Check, Create. Unfinished wizards are kept across Unity restarts.

Wizard Makes
Item… any item: name, icon, stats, on-use effect, who drops it, who sells it, how it looks when worn
NPC… a monster, guard, vendor or quest giver, with loot and spawners placed from the Scene view
World Object… gatherables, chests, crafting stations, with their phases and actions
Loot Table… a drop table to attach to NPCs or objects
Dungeon… a dungeon instance: entrance, map, bosses

Content ▸#

Tool Use it for
Currency Shops The offers in honor, vocation and other currency shops, and the currency names and icons the client shows

Characters & Gear ▸#

Tool Use it for
Characters and Races Body prefab for every race and gender; sockets; what each body wears. Opens the Dev Tools tab
Gear Workshop Fit a weapon or armour piece on any race and gender, live in the Scene; save it for everyone or as a body variant. Opens the Dev Tools tab
Gear Visuals (Database) The table of gear visuals itself: one row per item and slot. Edit any field directly
Import Outfit Pack… Turn a modular outfit pack (FBX parts + textures) into HDRP materials and one prefab per part
Animation ▸ Create Character Animator Controller Creates AxiomCharacter.controller with every parameter and state the game drives
Animation ▸ Upgrade Selected Animator Controller Adds parameters added since your controller was made, without touching its clips
Check and Export Gear Visuals Re-registers and validates every gear visual row's prefab, runs the binding checks, then rebuilds gamedata.bin
Run Gear Binding Checks Binds sample gear to the default body in a hidden scene and reports anything that fails (bones, meshes)

Art & Assets ▸#

Tool Use it for
Make World Prefab From Selected Model Select an FBX in the Project window → a prefab with colliders, layer and LODs, registered under a model key
Select World Prefab Catalog Selects Resources/World/WorldObjectPrefabs.asset, the key → prefab list
Asset Audit Every model key and gear item: what's missing a prefab, what's wrong with it

Dev Tools in detail#

Open with Shift+Alt+D. Tabs are on the left, grouped; type in the search box (Ctrl+F) to filter; Ctrl+PageUp / Ctrl+PageDown move between tabs.

The status bar (top) is live:

Pill Green Click it
World DB the database exists, isn't locked, has every patch opens SQL Patches
MySQL, Auth, Persistence, World that server is answering on its port opens Server Control
Data StreamingAssets and the auth server hold the same gamedata.bin opens Overview

Ports default to 3000 / 7778 / 7777 / 5090 / 3306 (each server's appsettings.json).

The log (bottom) collects messages from every tab. Filter it by level, by tab, or by text; Copy puts the filtered lines on the clipboard; the arrow button changes its height.

Group Tab Use it for
Overview Overview One-screen health check with a fix for everything red; Export game data now; shortcuts
Content & Data Content Studio Shortcuts into Content Studio
Game Data Paths and manual steps for gamedata.bin
SQL Patches Every patch, and which the database has applied
Characters & Gear Characters & Races Races; a body slot for every race and gender; Sockets (each body's hand, back, hip and head points); the Wardrobe grid
Gear Workshop Fit and save gear on any body (automatic sockets by weapon kind, sheathed size); import outfit packs
World Building World Map, World Tiles, Zones, HLOD Proxies, NavMesh, Doodads, Spawn Points Building the world: see WORLD_BUILDING_GUIDE.md
Diagnostics Validate Spawners and spawn points against the database and terrain

Every tab has a ? button that opens its guide.

Adding your own Dev Tools tab (programmers)#

Create a class in Assets/AxiomMMOKit/Editor/DevTools/Tabs that implements IDevToolsTab and has a parameterless constructor. Dev Tools finds it by reflection; there is no list to register it in.

public class MyTab : IDevToolsTab
{
    public string Title => "🔧  My Tool";
    public int Order => 30;                                  // position inside its group
    public string Category => DevToolsCategories.Content;    // sidebar group
    public string Description => "One line saying what it's for.";
    public string HelpDoc => "10_ADDING_ITEMS.md";           // the ? button

    public void OnEnable(DevToolsContext ctx) { }
    public void OnDisable(DevToolsContext ctx) { }
    public void OnGUI(DevToolsContext ctx)
    {
        EditorGUILayout.BeginVertical(ctx.Styles.Card);
        EditorGUILayout.LabelField("Hello", ctx.Styles.CardTitle);
        if (GUILayout.Button("Do it")) ctx.Success("Done.", "My Tool");   // goes to the shared log
        EditorGUILayout.EndVertical();
    }
}

A new menu item takes its path and priority from Editor/Core/AxiomMenu.cs and gets an [AxiomTool("what it does")] so Home > Tools can list it. Fixed asset locations come from Editor/Core/AxiomAssetPaths.cs. A static method under AxiomMenu.Validation is picked up by Run All Checks automatically: throw to fail. Full details: EDITOR_TOOLS_REFERENCE.md (Help > Reference).
