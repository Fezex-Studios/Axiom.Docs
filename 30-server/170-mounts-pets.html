Mounts & Pets#

Piece File Job
MountManager Core/Companions/MountManager.cs Mount/dismount, speed multiplier, flying, dismount rules.
PetManager Core/Companions/PetManager.cs Summon/dismiss pets, owner buffs.
MountTable, PetBuff GameData/Mounts, GameData/Pets Mounts, PetBuffs rows.

Mounts#

A mounted player is the same player, moving faster, drawn with a model under them. No second entity, no vehicle.

  • Summoned by using an item whose effect is Mount (Effects.Kind = 4, RefId = Mounts.Id). Using it again dismounts.
  • Mounts: Name, ModelType, SpeedMultiplier (1.8 = +80 %), CanCarryPack (pack mounts can carry trade packs), CanFly, FlySpeedMultiplier, FlyVerticalSpeed.
  • Mounting changes the session's Mount component; AuthoritativeMovement notices the profile changed and sends a new W2CMovementConfig with the faster profile (Movement). The server stays the authority on speed.
  • W2CMountState tells everyone nearby (which mount, how fast, whether it can fly).
  • Dismount on taking a hit, attacking, dying, harvesting: one Dismount method all those call.
  • Not saved: you log in on foot.

Flying mounts (CanFly = 1): hold jump to take off (LocomotionMode.Flying), climb/dive with the input pitch at FlyVerticalSpeed, fly at run speed × FlySpeedMultiplier. Never inside a dungeon. Getting off (or knocked off) in the air is an ordinary fall. The Flying movement-state bit is stripped from anyone not on a mount that may fly right now.

Pets#

A pet is a normal NPC (same spawn path, id range and visibility) whose AI state has an OwnerPlayerId: it follows its owner (PetFollowDistance 3 m) instead of wandering, and never picks a fight.

  • Summoned by an item with a Summon Pet effect (Kind = 5, RefId = the pet's NpcTemplates.Id). One pet per player; using the item again dismisses it; dismissed on death and disconnect.
  • Buffs: each PetBuffs row (NpcTemplateId, StatusId, Sort) puts a permanent status on the owner while the pet is out (a hound +movement speed, an owl +Spirit, a cat +crit). What it does is the status's StatusModifiers.
  • World:PetsBlockPlayers (default true): pets block other players; the owner always walks through their own.

Recipes#

A new mount#

INSERT OR REPLACE INTO Mounts (Id, Name, ModelType, SpeedMultiplier, CanCarryPack, CanFly, FlySpeedMultiplier, FlyVerticalSpeed)
VALUES (4, 'Ironhoof Elk', 'Mount_Elk', 1.9, 0, 0, 0, 0);
INSERT OR REPLACE INTO Items (item_id, name, description, icon_name, category_id, rarity_id, required_level, bind_type, no_trade, max_stack, vendor_price)
VALUES (7004, 'Ironhoof Elk Whistle', 'Summons your elk.', 'Items/mount_elk', 5, 3, 10, 1, 1, 1, 0);
INSERT OR REPLACE INTO ItemUses (Id, ItemId, ConsumeOnUse, EffectType, EffectValue, CooldownMs, CooldownGroup, CastTimeMs, LaborCost)
VALUES (7004, 7004, 0, 0, 0, 1500, 0, 1000, 0);                              -- 1 s summon cast, not consumed
INSERT OR REPLACE INTO Effects (Id, OwnerType, OwnerId, Sort, Kind, Target, Min, Max, RefId, DurationMs) VALUES (7004, 1, 7004, 0, 4, 0, 0, 0, 4, 0);

Client: a Mount_Elk prefab with a rider socket and locomotion animations (Characters, Animation guide (archive)).

A new pet with a buff#

INSERT OR REPLACE INTO StatusTemplates (Id, Name, Description, IconName, IsDebuff, DispelType, StackRule, MaxStacks, DurationMs, TickIntervalMs, Crowd)
VALUES (5010, 'Fox Companion', 'Critical chance increased by 2%.', 'Status/fox', 0, 0, 0, 1, 0, 0, 0);
INSERT OR REPLACE INTO StatusModifiers (Id, StatusId, Stat, Flat, Percent) VALUES (60, 5010, 10, 2, 0);   -- Stat 10 = CritChance
INSERT OR REPLACE INTO NpcTemplates (Id, Name, Level, ModelType, InteractRange, IsStationary, MaxHealth) VALUES (90500, 'Red Fox', 1, 'Pet_Fox', 2, 0, 0);
INSERT OR REPLACE INTO PetBuffs (Id, NpcTemplateId, StatusId, Sort) VALUES (10, 90500, 5010, 0);
-- the item: Effects Kind 5 (Summon Pet), RefId 90500
